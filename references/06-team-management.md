# 团队管理：基本逻辑 + 八大管理工具

用途：用户带团队拿不到结果、目标没拆到人、要向上汇报、要复盘、要做 1on1 / IDP / 人力盘点、带新人、团队士气问题。

**管理观：对结果负责是根本；管好人是为了更好地对结果负责。氛围好但拿不到结果的团队毫无意义。**

---

## 1. 团队管理的基本逻辑

```
高层：战略决策 + 整体业务模型
  ↓
中层（AB 类操盘手）——对结果负责
  管事线：定目标做规划 → 目标拆解到人 → 按阶段跟进（周/双周/月）
          → 进展不如预期 → 调整（调事：方法逻辑 / 调人：人岗不匹配）
          → 周期末（Q / 半年）复盘 → 下一阶段
  管人线：人力结构盘点 / 各种谈话（绩效 / 发展 / 情绪 / 辞退）/ 团队凝聚力 / 重点员工辅导
```

### 案例·小 H（历史人文地理纪录片 APP 业务线）
- 假想模型：大量纪录片 + 定期上新 → 留存活跃 → 付费 → 续费。目标 Q3 日活 1 万。公式：日活 = 新增用户 × 次留 + 当日新增。次留低是最大洼地 → 两条线（大量免费内容 + 稀缺内容引入：内容 BD；内容消费路径：产品经理 + 内容运营）+ 新增强依赖投放。
- **错误**：1 万指标只放自己身上，只给内容 BD 定了"每月 8 家 PGC 机构"，投放 / 内容运营 / 产品 / 小程序同学全无 KPI，工作模式 = "这周帮我干三件事"。
- Q3 末日活 2000。分析：投放用户太分散精细化跟不上；看纪录片下载 APP 成本高，小程序更优；高校大学生留存高于其他。
- 调事：Q4 小程序为主载体、重点打高校、传统文化 / 社区话题。重梳模型（干掉渠道投放和自然用户；原有用户群 + 高校社团 → 小程序社区圈子话题运营 → APP）。指标变小程序日活。
- 调人 / 分工：社区运营 + 产品经理共背次留；2 个 BD 每月 30 个社团；活动策划每月几场活动、每场多少新增；社群运营多少个群输送多少新增 → **目标没达成能分辨是 BD 不给力 / 社团导不上来 / 次留接不住**。
- 人的问题：团队转岗而来基础能力匮乏 → 员工辅导；方向调了三次动力缺乏 → 激励；老板传统媒体人不同频 → 定期汇报。
- 回扣四特质：时间窗口有限，人撑不住目标就果断换人；基于假设不断调整模型；目标分解到每个人提清要求才可能拿到结果；管事管人都不可缺。

## 3. 工具详解

### 3.1 汇报框架

**规划型汇报 5A**（时间占比建议）
1. Aspiration 愿景目标（短但要有）：解决什么问题、目标、愿景
2. Assessment 全面评估（20%）：背景、重点难点
3. Actions 举措建议（50%）：每个问题 / 障碍背后的思考
4. Action plan 实施计划：3-5 个月怎么做
5. Advancement 推进保障：风险及防范、需要的前提保障

例："老板，我建议 Q4 集中探索小程序方向先拉高校用户，原因三点；目标小程序日活 3000。评估：市场 / 产品模式 / 参考借鉴 → 可达成。重点三点。计划：第一个月 BD 30 家社团 + 线下活动，看进展再规模化。保障：加两个高校 BD，换产品经理。"

**实施中进度汇报**：背景（简短）→ 执行情况（原计划 vs 现状）→ 评估（顺利则一切 OK；有问题讲挑战和原因）→ 建议（不仅提问题还要回答问题）→ 需要的支持。
例："以高校社团为获取点打开小程序用户量，跑一个月：BD 10 个社团拉新 1000，月留存 20%，人力消耗大 → 这条路不太行 → 原因两点 → 建议换打法下月快速验证 → 需几点支持。"

**问题解决型汇报**：分析形势 → 界定问题（存不存在 / 真正影响因素）→ 原因分析 → 解决方案 → 判断与预期结果（多长时间 / 难度 / 什么条件下发生）。

### 3.2 目标管理 + 进度管理

两种方式：
- ① 拆到人直接要结果：适合团队战斗力超强 / 目标清晰探索少 / 高度信赖 / 高层。高层长期冲一线 = 高层缺位。
- ② 既管结果也管过程：中层 / 战略级战线 / 需探索定义、动态调整的项目。**AB 类先学会管过程拿结果，再谈用人。**

**周节奏进度管理**：
- 阶段性目标（Q 内获客每天 500-1000、付费转化 5% → 10%）→ **leader 自己拆成每周计划**（一线执行者不能让他们拆）→ 本周 N 件事（三套投放素材模板 + 5 个投放计划上线，下周看数据）。
- 周一定计划 / 周三 review 进展不跑偏 / 周五 review 达成情况 + 讨论问题 → 调下周 → 下周一新计划。
- leader 主线 = 阶段目标 / 每阶段计划 / 达成情况 / 问题如何指导下阶段。不陷入具体执行问题，做支持者。

**OKR 要点**（葛昊加餐）：
- OKR 不是绩效考核工具，是人才观和管理理念，落实目标一致 / 信息透明 / 自由发声三要素。O = 做什么，KR = 怎么衡量。服务战略（3-5 年愿景 → 1-3 年战略 → 年度目标 → 1-3 月阶段目标）。
- 例：产品部 O"提升首次用户体验"KR：找出并实施核心指标 / 首次登录三项实验符合预期 >50% / 发布两个迭代版本核心功能采用率 +5%。运营 O"扩大新媒体内容影响力"（而非粉丝数）KR：粉丝 +2000 / 一篇 10 万+ / 200 条销售线索。市场 O"确保线索和机会质量活性"。
- 注意：目标要有野心、超出能力一点（不与工资挂钩）但上下级协调；O ≤5、每 O KR ≤4，少写；KR 有截止日期可量化；60% 自下而上（目标自上而下分解，KR 一线提）；达成共识非独裁（员工提意见、双方一致才叫共识）。
- 打分满分 1 分，0.6-0.7 理想；过程比分数重要；全公司做；不与工资关联；听执行人意见。周期：Q 前起草 → 中期 review → 结束总结打分公布新的。
- 失败原因：管理层理解不到位靠 HR 推不动；缺信息系统支撑。

### 3.3 复盘模板（四步，一定基于目标）
1. 回顾目标：当初做什么事、目的、目标和里程碑
2. 评估结果：哪些达成哪些未达成（超预期 / 达预期 / 不达预期 / 不可评估）
3. 分析原因：分主观客观；**成功多看客观（运气 / 红利），失败多看主观**
4. 总结规律 + 下步行动：沉淀经验规律；行动分 **继续保持 / 停止做 / 新开始做**

例·产品团队 OKR 复盘：O1 100%、O2/O3 70%、O4 40% → 有效：复盘反馈机制、中台化思考进步；需改进：与研发和业务协作差、推进无节奏感 → Q3 重点 + 两件新事 + 协同方案。

### 3.4 人力结构盘点 + IDP

**人力盘点**：中层承担有挑战的任务、团队十几人以上 → 评估结构能否支撑一年内目标。工具 = 绩效 × 潜力九宫格（S / A1 / A2 / B1 / B2 / B3 / C / D）。B 为合格，S 高潜。S+A 占比至少约 30% 才积极；多在 B/C/D 目标难实现。得出最缺哪类人（高潜有成长空间 vs 一堆没潜力出不来业绩）→ 指导人员工作重点。可求 HR 支持。

**IDP 个人发展规划**（王刚）：结合岗位需要 + 个人意向，管理者与员工沟通达成共识的系统性提升计划。典型场景年度 / 季度总结。
四模块：
1. 工作回顾与评价：具体指标事实；含组织贡献（带新人 / 面试 / 团建 / 分享）；上级写满意否、原因、哪些指标未达、哪里可更好
2. 个人优势与成长机会点：用"机会点"不用"缺点"，动态具体（"了解客户需求方面可做更多"优于"沟通技巧不足"）；用 STAR 提问核实；抓关键不求多；对应岗位胜任力模型
3. 职业兴趣探索：1-3 年短期、3-5 年长期，>5 年不纳入；维度岗位 / 职级 / 薪资 / 地点 / 行业，引导排序
4. 下一步培养计划：有时间、有产出、可考核；共性需求集中培训

流程：员工先填 → 上级补充评价 → 1 小时深度一对一 → 书面记录 → 至少每季度回顾。注意：有仪式感（打印纸本、无人打扰会议室、整天只做这件事）；少说多听多问以启发为主（做蜡烛点燃自主进步动力）。

### 3.5 1on1 沟通

场景：目标传达 / 过程管理 / 结果反馈 / 绩效沟通 / 情绪管理 / 离职留任 / 任务复盘。

**三长两短反馈法**：先说三个做得好的（有事实数据）→ 再说两个可提升的 → 补充点评。上对下、下对上都适用，有理有据引导到积极氛围。
例：独当一面负责服务号 / 22 篇推文转化率 +2% / 内容质量提升阅读分享率涨 / 主动复盘 / 拓展边界做增长活动新增 8000 粉 ‖ 内容相比行业优势水准还不够；偏执行，Q1 要加强全局规划不要等我提需求。

**PLAN 模式**（王刚）：管理者发言 ≤30%，员工 ≥70%；30 分钟左右最长 1 小时（重要且打开了就聊透）。
- P Purpose：开场说清目的和时长 + 破冰（"你来两个月了，今天花 20 分钟聊聊状况"；年终"一小时：你先介绍业绩 → 我点评评估 → 一起讨论发展计划"；关心病假家事、递水零食）
- L Listen：先让员工说，开放式问题（"你给自己打几分""先回顾一下这一年"），不先抛观点否则抵触
- A Ask & Answer：多提问不否定（想转岗 → 问为什么；状态不好 → 关心具体什么事；要升职加薪 → 问为什么现在 / 动机 / 长短期期望），了解够了再针对性反馈（好的肯定、不足批评 + 改进计划；当场解决不了记本子上给回复时间点）
- N Next step：有结论，员工写沟通纪要邮件发管理者，含员工改进计划 + 管理者提供的支持（双方承诺），后续在此基础上续发
- 氛围：谈心不是审问，复述再提问，90 度侧坐 / 边走边聊，先心情后事情

### 3.6 团队发展与激励模型（四阶段）

| 阶段 | 成员状态 | leader 重点 |
|---|---|---|
| 建立期 | 彼此陌生、未来模糊、不安不信任 | 面对面会议定义目标 / 团队架构 / 协作方式 / 每人角色 / 工作方式 / 决策程序（什么要请示、什么可自决，授权讲清）；**就职演说**（先花两周接触上级 / 重要下属 / 兄弟部门 / 关键客户再讲；三部分：个人职场生活经历建立信任 + 管理风格[最希望的工作方式 / 最欣赏的品质 / 不能容忍的底线，把丑话说前面] + 工作方向[与前任异同]；定了规矩要执行，触犯底线要杀鸡儆猴，别一上来三把火） |
| 磨合期 | 困难冲突大量出现、个人喜好前置、信任未建立 | 身先士卒搞定下属搞不定的事（K12 校长：每天 200 个电话先做销售冠军，帮资深销售拿大单，才获信任）；大量 1on1 了解顾虑；重新审视目标和角色分工微调；及时介入调节冲突，甚至创造环境公开冲突（会议末留十几分钟畅所欲言）；每人承担一部分公共项目（对接财务 / 学习协调者 / 行业动态 / 轮流组织团建）制造链接 |
| 成型期 | 有合作规则 / 工具流程制度，关注目标而非关系，有归属感、接受角色 | 提升信任三件事：集体记忆（誓师大会、集体反省集体解决问题）、体验高峰（制造惊喜时刻）、里程碑事件（整数关口用户破 10 万、销售破 100 万及时传递；Uber "N 的 N 次方"；杭州最高旋转餐厅庆祝破纪录） |
| 表现期 | 目标被实现、里程碑刷新、士气高、不惧冲突 | 保持高绩效：退居二线支持自我领导；晋升优秀员工送出去；吸引新成员并授权老员工带新人建梯队；引入更高挑战避免自大 |

每阶段建立在前一阶段上；遇到新挑战新任务，阶段会重新开始。

### 3.7 EDAC 培训辅导技术（宝洁管培生起源）
- **E Explain**：讲清是什么 / 为什么（对公司和个人的意义、重要性）/ 怎么做（拆解步骤、流程、关注重点、给框架模板）；必要时让员工复述确认理解。反面："周五前帮我把宣传稿写好"信息不足。
- **D Demo**：完整标准可复制的流程示范（看我做一遍 / 看同事成功案例完整复盘文档）；以新人视角不省略；也是管理者保持与一线接触的机会。
- **A Apply**：给子任务真刀真枪试；观察 + 事后反馈（好的 / 可提升 / 下一步改进；让员工先自评再点评）。忌控制欲太强（偏离就打断 → 应记录事后反馈，可承受范围内让他狠狠失败一次）和心太软（跳步结果没出事就放过 → 必须指出重走四步；任正非"先僵化后优化再固化"）。
- **C Consolidation**：实战演练持续布置类似任务关注熟练度；或高压模拟任务（扮演谈判对象制造麻烦打断呵斥；每周一篇宣传稿集中训练；姚明体力耗尽时练罚球）；员工压力大时不宜。
- 宝洁管培生 8 周：四模块（管流程 / 管客户 / 管生意 / 管团队）各有课程 → 内部成功案例库 → 尝试任务（独立完成一次客户拜访并填日志 / 独立卖进 3 个新品分销上架 / 完成一次促销结果分析并与客户回顾 / 召集一次销售代表会议辅导业绩）→ 考试（角色扮演促销宣讲 / 专题汇报如何提升新品卖进率 / 品类知识陈列标准笔试）。
