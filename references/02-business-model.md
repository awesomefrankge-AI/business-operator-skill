# Frank 方法模块：业务模型的梳理、搭建与优化

用途：用户要梳理公司 / 客户的业务模型、算收入公式、判断自己该关注什么、从 0 搭一个局部模型、评估一个模型好不好。

**操盘手第一要求：把业务经营管理模型化**——公司管理 = 一个公式，管理 = 控制公式里的变量。

---

## 1. 定义

- **业务** = 能独立产生商业价值的经营单元：产品 / 服务是什么、用户是谁、通过什么渠道触达、产出什么商业价值。
- **业务模型** = 稳定 input → 一套有逻辑的体系（规则 / 协作机制 / 业务流程）→ 稳定 output。给我 A，一定给你 B。服务于商业模式，让业务可规模化。
- 意义：进入任何业务已成型的公司，脑中要有整体业务模型 + 自己负责的局部业务模型的清晰认知或假设。

## 2. 全局业务模型的构成

```
┌ 整体业务增长模型（重中之重）：收入 / 商业价值产生和持续增长的链条 ┐
│   流量来源 → 转化路径 → 付费 → 复购 / 增值                          │
├ 生产供给交付保障体系：生产研发流程 / 供应链管理 / 交付服务保障       ┤ ← 与上层环节一一对应
├ 基础工具 & 效率系统：在线系统 / 教务系统 / 中台（可省略）            ┘
```
实质：input（钱 + 基本生产资料）→ 运营体系 → 更大收益。

**"流量→转化→付费"三个框没有任何价值。** 必须细到具体渠道、产品线、收入来源，才能得出可驱动的收入公式。

案例·长租公寓：线索 3 渠道（房源平台投放 / 在线社群 / 沉默老用户外呼）→ 到店看房 → 3 类房源（促销特价 / 品牌整租 / 低价整租）→ 签约付费 → 续租 + 在住增值（金融 / 到家 / 会员 / 电商）；下层房东 BD 供应链、租客服务保障。
收入公式：
- ①（投放线索 + 社群线索 + 召回线索）× 到店看房转化率 × 平均租住周期 × 月租均价
- ② 老用户总数 × 续租率 × 平均租住周期 × 月租均价
- ③ 在住其他消费

前提：业务相对成型。草莽期"哪块业务稳定都不知道"梳理不出来。

## 3. 梳理整体增长模型：1 个基本逻辑 + 4 个问题 + 3 个额外思考

### 3.1 一个基本逻辑：按商业模式画雏形，再落到具体产品功能和用户路径

| 商业模式 | 商业价值诞生路径雏形 |
|---|---|
| 流量 + 广告 | 获流量 → 维系留存放大 ‖ 找广告主 / 线索 → 销售转化 → 变现 |
| 平台 + 抽佣 | C 端 / 需求端流量 + B 端 / 供给端资源 → 平台规则撮合交易 → 抽佣 → C 端复购 / B 端留存 |
| 产供销 | 流量获客 → 转化路径 → 付费 → 复购（单一复购玩法 或 LTV 生命周期运营体系） |
| 免费 + 增值 | 流量 → 免费产品注册使用 → 持续使用运营 → 用户分层 → 部分增值付费 |

落地案例：房产交易平台（C 端 PR / 效果广告 / 线下 / 小程序 → 分层引导 → 二手房 / 新房 / 租赁 / 海外业务线 → 线上 / 线下转化 → 成交；B 端拓展 → 邀请入驻 → 标准化培训 → 承接商机）；游戏平台（买量 → 下载 → 注册 → 新手引导 → 次留 → 首充破冰 → 分层 + 成长体系 → 持续付费）。商业模式大同小异，业务模型各不相同。

### 3.2 四个问题

| 问题 | 若是，则 | 案例 |
|---|---|---|
| Q1 对不同用户 / 渠道是否存在不同的稳定转化路径？ | 把每条能独立稳定成通路的路径单列为独立增长引擎（不必穷尽，只列稳定持续的） | 健身教育平台：投放留表单电话触达 / 社区免费低价培训 / 高校公开课 三条线索路径 |
| Q2 核心产品是否重决策 / 非标 / 高价？ | 链条必须加**体验产品或辅助决策型产品**，把流量引到体验产品 | 买房 / 高价课 / 企业采购系统 / 咨询 → 测评 / 主题看房 / 公开课 |
| Q3 产品线是否多元 / SKU 多？ | 单一 → 转化路径尽量单一简单易驱动；多 → 必须给产品分类 + 理清关系（入口产品 / 分流逻辑 / 复购成长路径）或拆成独立业务模型独立团队，否则各产品线抢流量无法决策 | 电商三类：爆款（低价走量，月几万单）→ 利润产品（爆款带货复购引导）→ 防御型 / 附加产品（手机壳贴膜，留住消费习惯）；4 渠道流量集中导爆款 1/2 |
| Q4 是否需要长期用户生命周期管理？ | 短（托福雅思）→ 单线程路径（导入 → 注册试听 → 首购 → 二次附加 → 流失）；长（懂球帝 2-3 年）→ 注册后必须有用户分层 + 长期维系体系 | 游戏：免费 / 小额 / 中额 / 大额分层 + 每层权益策略 |

### 3.3 三个额外思考

| 思考 | 分支 | 案例 |
|---|---|---|
| T1 单一产品售卖生命周期长短？ | 短（≤6 个月：知识付费 / 快消 / 出版 / 饮品 / 数码 / 保健品 / 部分社交 APP）→ 增长靠海量上新 / SKU 增加 / 快速迭代，模型需海量选题上新的生产逻辑；长（4-5 年：教育 / 医疗 / 金融 / 大宗消费）→ 靠稳定转化链条 + 稳定交付 + 用户增长驱动 | 某垂直培训业务的历史复盘：主打大 IP / 话题的课 → 用户预期离散 → 无口碑 → 6 个月内拿走 90% 收入；目标人群和教学目标明确的课 → 口碑 → 卖 5 年逐年涨（50 万→100 万→三四百万→六七百万） |
| T2 是否需持续搞定稀缺资源驱动增长？ | 是 → 围绕稀缺资源的 BD 和运营单独构建体系，作为增长引擎 | 会展公司收入 = 搞定几家行业协会 / 头部媒体；2014 IT 招聘每月 BD 三五百份前端工程师简历 → 企业注册与流量涨 |
| T3 增长是否受供应链制约？ | 是 → 下层必须有强供应链管理体系与营销增长联动 | 教育 3 个老师 × 200 人/班 = 月上限 400 单且要保满班率 ≥80%，排班与售卖联动；酒旅房源 / 电商 SKU 库存 / 滴滴运力；房产平台按城市扩张需供给基数 + 质量 + 稀缺房源 |

### 3.4 案例串讲（1+4+3 完整应用）

- **Airbnb**：平台抽佣雏形 → Q1 一线用户（风格装修主题）与三四线用户（价格）分两条路径 → Q2 住宿较标准不加 → Q3 房源多，分 A 类（一线易转）B 类（三四线易转），房源拓展入库维护下沉为供应链体系 → Q4 出行一年 4-5 次需长期管理 → 会员运营体系提 LTV → T1 房源生命周期长不需上新 → T2 三四线优质高性价比稀缺房源 → 单独拓展运营体系 → T3 每开一城需供应链配合 + 地区订单需求平衡。
- **小红书（只看社区）**：流量生意 → Q1 KOL vs 普通用户互为供需、一二线 vs 三四五线话题不同分开 → Q2 否 → Q3 功能多需梳理用户成长路径 / 引流功能 / 进来后往哪走 → Q4 需分层精细化运营 → T1 否 → T2 KOL / 好话题 / 好内容是稀缺资源需配套运营机制 → T3 否。
- **跟谁学高途（K12 小班直播）**：线索 → 试听体验课 → 付费 → 续费 → Q1 一线 / 三四线分开 → Q2 高价非标必须体验课 → Q3 课程多但一年级续到六年级逻辑简单 → Q4 需长期管理 → T1 长 → T2 老师非名师不算稀缺 → T3 小班 5 人老师资源浪费，师资班期必须与前端流量联动。

## 4. 局部业务模型

- = 全局模型中某一核心环节 / 模块单拿出来；处于链条某一环，需明确上下游、资源投入和目标、与哪些业务方对接联动；是完整商业系统的子系统。
- input（特定业务资源 / 人 / 钱 / 生产资料）→ output（稳定标准的业务价值：某环节转化率 / 满意度 / 人效 / 收入）。
- **四要素**：流程、SOP、约束机制（利益分配 / 激励 / 品控 / 考核）、角色分工。
- 两类常见：增长导向（input 流量 / 钱 / 资源 → output 订单 / 新增用户 / 收入，如 toB 会销每场会议）；生产交付保障（input 生产资料 / 初始状态用户 → output 成品 / 高满意度 / 续费）。

**梳理四步**：
1. 明确 input / output
2. output 主要靠流程保障还是靠分工协作机制保障
3. 先搭业务流程（班期制培训业务）或先搭角色分工（樊登读书会）
4. 补配套约束机制（激励 / 品控 / 考核 / SOP）

- 简单业务：流程画出来就七八成（某训练营业务：讲师 BD → 课程研发[立项评审 → 大纲 → PPT 录制] → 班期教学[开营 → 每周看课 → 作业 → 毕业设计反馈]，补每周看什么数据调什么策略）。
- 复杂业务 = 角色多 / 用户类型多：先界定 input / output → 列出角色及关系分工 → 再串协作流程和各角色策略（教育平台个性化辅导：running partner / 教研 / 助教 / 班主任 × 学前学中学后；美团用户分层：按历史订单数 × 最近购买时间分十几类，每类定义 + 策略，类之间不需发生关系，后端再补部门协作流程）。
- 案例·樊登读书会城市合伙人：省分会（官方给渠道扶持政策资源）→ 城市分会 → 县区分会（配樊登书店实体承载活动）→ 企业分会（小驿站），三级分销利益分成，以省为中心；input 人力和钱，output 稳定会员增长。

## 5. 评估一个业务模型好不好（两问）
1. input / output 稳不稳定、能不能规模化？**不能规模化的模型毫无价值**（只有我一个人能写爆款文案 ≠ 模型；短期破局可以，长期必须搭模型）。
2. 在行业内是否有强竞争力和增长驱动力？有无壁垒 / 独特优势（Airbnb 房源拓展能力天下第一）；收入公式清晰否、易驱动否（需要 20 件事同时发生 = 难驱动；一个地区一套打法每次 100 万一年 50 次 = 5000 万，清晰易驱动易定位问题）。

## 6. 梳理业务模型对个人的意义与跑偏警示
- 早期业务：搞清要奔跑验证依赖的模型是什么 + 当下最重要的假设是什么。
- 成熟业务：搞清该关注什么信息、贡献什么价值才不跑偏。哪怕再不起眼的事，都要与核心业务模型衔接。

**四个跑偏反面**：
1. toB 公司新媒体部搞 10 万粉、20 篇 10 万+，与企业线索无关 → 无价值。
2. AB 轮公司品牌部大咖活动事件营销，讲不清对主业价值。
3. 社区运营总监拍脑袋做全国粉丝会，几百个群、五六人、四五个月，与内容 / 流量 / 留存无关 → 被干掉。
4. 百度 2013-14 做教育：教研教学交付基因 ≠ 流量基因，是开辟新基因而非放大已有基因 → 失败。

忠告：早期公司 = 边干边动态完善模型，跑通后定型规模化放大；成熟公司 = 所有工作不能逆现有业务模型而行，要么借助其核心资源，要么为它服务（更强健 / 规模 / 效率）。

**组织结构服务于业务模型**：选了模型必须有匹配的组织架构。一家在线培训企业的组织调整案例：旧模型（按市场热点话题策划选品 + 单课营销）→ 渠道市场部 / 品类运营部 / 教学服务部；新模型（社群体验小课集中转化少量几类课）→ 营销中心（渠道 → 小课 → 转化，对订单收入满班率负责）/ 学习中心（研发交付稳定、教学目标口碑、给营销弹药）。阿里约每半年调一次组织结构。理解了业务模型就不会害怕组织调整。

## 7. 从 0 跑出一个局部模型

### 7.1 成型过程需要时间（企业培训服务商案例，1 年+）
- 2017 随机零散：大厂找上门来一个接一个；交付完全靠 CEO 个人临场发挥 → 获客和交付都不稳。
- 中期：搭销售转化雏形（人肉 BD + 买少量企业线索 + 招聘网站合作找培训负责人 → 10 人销售团队定向跟进卖训练营），有模型但不稳定。
- 交付：一人牵头 3-4 个月在 10 家企业落地打磨 → 输出交付模型（分周期 / 每周期目标 / 角色 / 机制 / 验收指标）→ 2018 稳定。
- 前端优化：加辅助决策产品（HR 社群 + 低客单价体验课）→ 转化率稳定 → 业务成型可评估成本收益。
- 中早期公司业务初步成型至少小一年。

### 7.2 从 0 搭建的逻辑（品类运营培养案例）
问题：3 个品类各需人做策略规划达成收入目标，岗位画像市面没有 → "人的培养"命题。
1. 向外找参照：宝洁 / 阿里的 **EDAC** 模型（Explain 方法教程 → Demo 真实示范 → Apply 带着练手 → Consolidation 独立负责小项目结项巩固）
2. 拆细岗位工作内容（基础工具方法 / 常见模块：单班期推广策划、单 SKU 增长策略、单品类整体增长策略 / 进阶方法）
3. 每个模块落到 EDAC 四格表
4. 放几个新人跑 1-2 个月验证调整
5. 定型：画像满足 3 条件 → 3 周上岗

逻辑：先找外部模型 → 再看它能否帮你获得稳定 input / output。

### 7.3 忠告：简单模型 vs 复杂模型
- 简单 = 单线程、变量少、分支少（工具产品），1 个月内能出答案。
- 复杂 = 多线程 + N 多人与人交互（每个人都是变量）+ N 多信息交互（A 信息制约 B 行动），周期长风险大（沃尔玛供应链 100 年；美团外卖后台运力测算 / 单量预测 / 派单 / 补贴定价；教育教研教学用户互动节点多）。
- 复杂业务的公司须：局部有成熟经验可借鉴、或雄厚资源、或几个模块已跑稳。
- 反面：校园团队把"转化产品未验证 + 公号投放 + 老带新权益（年度 4 场大咖直播）"三件事揉在一起 → 互相影响无法归因 → 没有定量只有变量 → 一地鸡毛。
- **忠告 1**：新项目搭模型，要么是别人跑通过的成熟模型（定量，跑不通就是执行不到位），要么足够简单、单线程、变量少。
- **忠告 2**：没有成功经验和手感，别直接上手搭复杂模型；能搭复杂模型的 leader 是把过去经验手感当最大定量。
