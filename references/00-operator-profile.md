# 商业操盘手画像、成长路径与自诊断

来源：三节课《商业操盘手培养计划》导论（黄有璨）。用于：判断用户处于什么层级、该走哪条路径、课程边界。

## 1. 操盘手的四种特质

| 特质 | 含义 | 案例锚点 |
|---|---|---|
| 着眼外部，杀伐决断 | 外部变化来临时果断拍板，砍掉现有资源和系统 | 2019-11 电子烟线上禁令当天决定转线下 |
| 运筹帷幄，决胜千里 | 不断建立 + 撬动放大核心模型，脑子里装的是模型 | 同时验证自营店 / 品牌店入柜两种模型 |
| 使命必达，强力破局 | 极致思考 + 极致行动，化不可能为可能 | 30 天全国开出 100 家线下店 |
| 无坚不摧，建精锐之师 | 不仅自己强，能赋能团队，团队里有人比自己强 | — |

## 2. ABC 三层操盘手

| 层级 | 典型岗位 | 能搞定的环节 |
|---|---|---|
| A | 大公司项目 leader | 上级给命题，自己给答案；搞定局部业务模型 |
| B | 小公司部门负责人 | 同上 |
| C | 大公司独立业务线负责人 / 创业者 | 局部 + 公司战略 + 外部市场判断 + 全局业务模型搭建 |

路径：先 AB，再 C。C 类附加条件靠时间积累：敏锐的体感判断（发一条朋友圈就能预判行业变化）、人脉资源、行业洞察。

**执行者 vs 操盘手的分水岭**：执行者"等靠要"（等老板给明确目标、靠上级给方案、要资源），操盘手"上级给命题，我给答案、给结果"。

## 3. 企业经营管理链条（五层）

```
战略 & 商业模式
  → 整体业务模型
    → 局部业务模型
      → 各战线规划 & 目标
        → 执行落地
```
多数工作 3-5 年的人只在第五层。AB 类至少要能对第三层给答案。

## 4. AB 类操盘手四项胜任力
1. 承上启下：拆解部门目标，独立做好规划
2. 上级抛的大部分问题能对话、能给答案
3. 作为突击队解决业务中复杂重要的问题
4. 带出可依赖、能快速成长的队伍

## 5. 五类典型障碍（自诊断用）

| 障碍 | 表现 | 对应模块 |
|---|---|---|
| 思考不同频 | 老板讲商业逻辑，你讲执行；方案被拍回来 | 01 高层同频 |
| 规划不靠谱、不简单、不明确 | "我要看 10 个指标" = 什么都没看；大而空或全是细节 | 04 规划 |
| 见识少 | 所有方案在小圈子打转（只会社群裂变 / 只会 SEM） | 03 模型库 + 跨界借鉴 |
| 管理不到位 | 目标不明确、士气涣散、不知道人员结构是否合理 | 06 团队管理 |
| 业务不精深 | 无法指导下属 | 课程不解决，靠实践 |

**探索型项目痛苦**（做了一堆 0→1 无一成功且不知道为什么）→ 05 探索。

## 6. 成长路径（自下而上）

```
基本前提：基础业务技能过硬 / 3 年+经验 / 职业素养        ← 课程不解决
  ↓
底层认知：商业思维 / 业务模型搭建与梳理 / 复杂问题拆解      ← 核心，第二章是灵魂
  ↓
四类深层能力：理解高层决策逻辑 / 目标明确时做靠谱规划 /
             模糊项目破局 / 团队管理                        ← 可按场景训练
  ↓
C 类附加：敏锐判断体感 / 人脉资源 / 行业洞察                 ← 只能积累
```

## 7. 边界与预期管理（对用户要诚实）
- 不适用：非市场化、关系导向行业（靠陪领导喝酒、靠拿地资源），"以用户需求和市场竞争为中心"的法则在那里失效。
- 不要幻想速成：方法知易行难，需半年到两年持续实践；50 分→70 分可以，30 分→80 分不行。
- 不欢迎三类人：只会评价不会做的嘴炮；遇事往后退缺乏担当；靠办公室政治解决问题。
- 初级操盘手的合理定位：**支持一个比你强的人掌控全局，用行动和执行帮他验证模型**，而不是替代老板。战略级决策 99% 的 3-5 年执行者触及不了。
