# 局部战场的目标制定与工作规划

用途：用户要定目标、拆目标、做半年 / 年度规划、接到模糊命题、资源不够要更快达成、独立负责一条业务线自己定目标、进度管理。

规划三步：**明确目标 → 拆解为工作计划 → 进度管理调整**。往前一步：目标从哪来（向上对齐商业经营逻辑和核心业务模型）；往后一步：工作先后节奏向团队表达。

---

## 1. 规划与模型的关系（目标从哪来）

- 业务模型清晰 → 收入公式精细化 → 团队 / 组织分工可据此推导。
  - 电商：收入 = 流量 × 爆款转化率 × 利润产品转化率 × ARPU；渠道 A/B 导爆款 1、C/D 导爆款 2 各算引擎；团队 = 流量团队（分渠道）/ 爆款运营（选品 / 渠道对接 / 前后端转化 / 向利润产品分发策略）。
  - 跨境电商指标体系：GMV = 新用户 GMV（新用户数[日均访问 × 注册转化率] × 付费转化率 × 客单价）+ 老用户 GMV（已购用户数 × 月活跃率 × 月购买转化 × 客单价）→ 营销团队背访问和注册转化；运营团队背付费转化率；品类运营背客单价；会员部门背老用户活跃率。
- 交付 / 供应链部门：收入公式要求交付稳定在什么指标区间、供应链吞吐量 / 效率 → 多一层映射。
- 商业经营模型 → 团队是成本中心还是利润中心 → 背两类指标：业务导向（来自在业务模型中的位置）+ 效率导向（来自成本 / 利润中心属性）。

案例：
- 企业培训服务商目标"3 倍增长 + 盈利"：收入 = 线索 × 转化率（两重）× 客单价；利润 = 销售额 − 销售成本 − 交付成本 − 其他。增长团队：3 倍来自提线索量 / 转化率 / 客单价 / 续费哪个更有空间；交付团队：支撑客单价提升（1 万→5 万）+ 卡交付成本不超客单价 X%（死线）+ 保稳定前提下提效（1 人月服务 2 家→5 家）。
- K12 外教目标"GMV +50%、ROI +15%"：增长侧降获客成本 / 提客单价 / 提转化率 / 扩流量；供给侧扩外教数量 / 提供应链响应 / 保质前提下提外教服务学员数 / 提班主任效率。
- 电商"线上 3 倍"：增长侧扩线上渠道 / 加强线下门店导流 / 提转化 / 提复购；供给侧供应链响应 / 降仓储运输成本 / 选品 / 线上线下数据打通 → 个性化推荐 → 转化率。

**AB 类操盘手做规划的基础逻辑**：充分理解高层战略 + 整体业务模型 + 经营逻辑（理解不决策）→ 明确局部现状和局部业务模型 → 据其状态属性定目标规划。
**应有心态**：战略方向讨论上给高层提供有效信息；全局模型梳理判断上参与部分讨论；局部业务模型上——上层明确要我达成目标 / 提升指标，或上层给方向要我验证答案 / 探索可依赖可规模化模型。所有信息回归到模型上思考。

## 2. 合理制定局部业务目标（三要求）

### 2.1 不跑偏：自上而下拆解

公司战略目标 → 核心业务 / 财务指标 → 各部门目标 → 二级 / 三级子目标。CEO 和部门 leader 拆解逻辑一致。

**两个角度**：
- **前提保障性条件（必要条件）**：销售招聘到位、新交易系统上线、APP 闪退率控制…… 要对齐时间节奏（20 个销售 1 个月内到岗 → 向 HR 提需求）。
- **进攻叠加性目标（充分条件）**：目标具化为一个数字，怎么叠加达成。
- 类比：买 10 吨苹果，"有钱"是必要条件；"A 渠道 5 吨 + B 4 吨 + C 1 吨"是充分条件。

**数字拆解三法**：
| 方法 | 逻辑 | 例 |
|---|---|---|
| 加法 | 按渠道 / 按产品 | 1000 万 = A 渠道 + B 渠道 + C 渠道；新媒体涨粉 = 自然涨粉 + 内容涨粉 + 活动涨粉[裂变 / 大号互推 / H5 / 投放] |
| 乘法 | 按路径漏斗 | GMV = 流量 × 转化率 × 客单价；培训业务 = 渠道流量 × 到体验小课转化率 × 到课程转化率 × 课单价 |
| 典型代表式 | 抓大放小 | 50 渠道 × 20 SKU 太复杂 → 找占比最大的 A 渠道 + B/C 产品；数千万用户级公司尤其要用 |

实践中多逻辑复合：培训业务 GMV =（渠道 A+B+C+D）× 小课转化率 ×（操盘手转化率 × 客单价 + 新人起航转化率 × 客单价）。滴滴 B=C：司机端订单 = Σ各产品线（激活司机数 × 首单率 × 在线率 × 抢单成功率 × 人均完成单），乘客端 = 注册用户 × 首单率 × 日活率 × 人均订单 × 应答率 × 完成率；管理逻辑 = 先预测 C 端总单量 → 分解到专车 / 快车 / 顺风车 → 看司机端供给对不对得上 → 对不上开源 → 看哪条线哪个因子最有放大空间。

**向上对齐**：搞清我的工作对上级是前提保障还是直接背他核心指标的一部分。**向下清晰**：我的目标需要什么前提保障、数字如何拆。

### 2.2 清晰、可衡量、可验收：局部战场四类目标

| 类型 | 来源 | 周期 | 要点 |
|---|---|---|---|
| ① 核心业务指标提升 / 降低 X% 或稳定在范围内 | 业务模型 / 经营公式 / 交付目标推导（最常见） | 3-6 月 | 先梳理清业务模型，看自己在哪个位置。例：健身教育平台营销部关注免费课 → 线索转化率 / 预约率 / 到课率 / 转介绍率 / 二次培训率；民宿平台 B 端产品团队：B 端产品 → 降房东问询量省客服成本 + 商业化工具提房源转化率；内部效率工具 → 单销售覆盖 5→15 房东提人均单产 |
| ② 做一件事实现重要短期阶段性效果 | 老板短期需求（骚扰竞争对手 / 为 PR 加势能 / 融资 PR），不一定与模型相关 | 3-6 月 | 搞清达成什么效果 + 怎么衡量。**效果可以问老板，衡量方式必须自己拿选项去确认**（融资 PR → 对投资人 PR → 覆盖 50% 以上顶级机构核心决策者且反馈正向）。老板可能说"看我感觉" |
| ③ 验证型：验证模型 OK / 不 OK，或探索可依赖新打法 / 新模式 / 新产品 | 业务升级需求 / 旧渠道衰退 | 3-6 月 | 定义"跑通" = **可复制可规模化**（KOL 投放：KOL 分 ABC 类 × 素材文案 ABCDE 类 → 不同组合投放的转化率和订单能稳定在数值范围）。一次投放成功 1000 单 ≠ 模型，只是单点动作 |
| ④ 长期系统工程：通过一系列工作让业务拥有某种能力 | 对自己模块的中长期想象 | 6-12 月甚至 2 年 | 需蓝图、分阶段（中台 666 规划：6 个月系统建设期六大模块 + 5-20 种子用户跑通 → 6 个月业务全面接入不重复造轮子 → 6 个月标准化组件化）；没蓝图 = 跑腿打杂 |

### 2.3 与协作部门对齐，不打架

两类团队：**业务团队**（增长 / 服务 / 交付 / 生产供给，处于业务流程某环节）vs **职能支持团队**（产研 / HR / 财务 / 法务，提供基础工具和效率系统）。

**业务团队对齐**：先把指标按公式拆清（横向按用户分类加法 / 纵向按漏斗乘法：月活 = 新增活跃[新注册 × 激活率] + 已有活跃[老用户 × 留存率]）。两种协作：
1. 跨职能作战单元对一个指标负责（运营 + 产品 + 研发）：定义谁驱动谁支持，驱动者背核心指标，配合者共背但非第一指标——产品驱动激活率，运营第一指标是按版本按时提供物料，第二才共背激活率。Pinterest 按流量 / 转化 / 激活 / 留存 / 推荐各环节小团队。
2. 多团队各认领一部分数字：新增 50 万 = 运营渠道 40 万 + BD 5 万 + 产品自增长 5 万。
- 上下游：线索团队第一指标线索数量，第二与销售共背转化率，否则互相甩锅。

**职能团队对齐两原则**：
1. 短期与业务部门目标对齐（共背指标，或我的工作是业务目标达成的前提）。
2. 长期必须有独立规划反向驱动业务效率提升（调研同类系统 → 10 个模块蓝图 → 与业务共识半年先做哪几个 → 形成产品自己的版本规划线），否则呼之则来挥之则去、一团混乱。

## 3. 把目标拆解为靠谱的行动计划

### 3.1 常规逻辑三步

**① 目标达成路径基本拆解（三步法）**：核心目标通过哪几件事 / 哪几个指标达成（进攻叠加：哪些数据要提升 / 降低 / 做出什么成果）→ 前提保障性条件（招多少人 / 研发保证哪几个版本上线 / 供给交付能力）→ 约束条件（钱 / 人 / 时间 / 工具系统资源限制，老板预期）。
规划顺序：先看资源限制只能做几件事 → 让必备前提保障先按时发生（倒推时间）→ 再开展进攻。

**② 对各分支战线设定预期，三种逻辑**：
- a. 多条战线赛马：不确定哪条能出，每条目标定高一点，谁先跑出 30-50% 就加投（渠道部门月 1000 万流量拆微信广告 / KOL / SEM / 信息流）。
- b. 每个环节恒定要求：对战场有清晰判断（总流量天花板 2 亿当下 1 亿、进店转化行业 25% 努力 30%、成交 8-10%、复购顶天 30%），都达到目标即达成。
- c. 关注先后顺序：前提保障先发生。

**③ 结合约束调整规划，三个出口**：
- a. 用行业成熟工具 / 套路，不造轮子（裂变 / 社群转化工具）。
- b. 找路径关键节点做减法，聚焦资源先解决最重要最高价值的问题（操盘手课先验证目标用户愿不愿付费再做课）。
- c. 时间紧、人有冗余 → 线性改多线并行。
- 例：增长负责人下半年 3000 万，5 人→2 人 → 先聚焦引流产品打开流量再做转化（或反过来）；人不变但 9 月要 2000 万 → 两条线两小分队同时推进 + 找外部可"一带多"的引流产品借鉴。

### 3.2 非常规问题一：模糊、需定义的问题

老板抛的是**现象**（PR 势能不高 / 社区氛围不好 / 团队士气 / 探索新方向），不是问题。三步：
1. **把现象定义为待解决的具体问题，验证问题是否存在**。口碑下滑 → 看满意度 / NPS / 推荐就业成功率 → 确实下滑 → 成因助教供应能力撑不住 → 定义为"搭一套支撑更大吞吐量的助教业务模型"。离职率 6% vs 行业 7% → 不是问题，用数据证明给老板。最终落到：做新产品 / 开新渠道 / 验证新模式 / 巩固现有模型。
2. **只模糊不复杂 → 对外找可借鉴模型定行动计划**。PR 势能差 → 定义为老板担心"对手融资威胁 + PR 驱动增长" → 约十几个 PR 专家各聊 1 小时 → 得到向投资人 PR 两种模型 + PR 驱动增长两种模型 → 给老板选项：投 100-200 万干 2 个月看成果。
3. **既模糊又复杂 → 层层分解找破局点先行切入**。创投媒体公司探索新业务：盘核心资源（企业家资源 / 行业影响力 / 活动社群能力）→ 产业链大机会（toB 服务 / 职业教育政策 / 投融资服务 / 高端社群）→ 结合基因选职业教育 + 企业服务 → 目标用户需求（C 轮前互联网创始人）→ 产品选项（数据 SaaS / 协同软件 / 高端咨询）→ 做法选项（自研 / 代卖 / 打包综合 SaaS）→ 关键：无论卖什么，toB 都是卖解决方案、需先诊断 → **破局点 = 培养一群牛逼的顾问式销售**，有了什么都能干。

### 3.3 非常规问题二：目标相同资源相似，要比别人更快 → 杠杆

先梳理一般达成路径 → 找一两件有杠杆效应的事显著加速（3 渠道各 200 万 → 其中一个渠道倾注资源打透打爆做到 400 万）。

**三类常见杠杆**（可叠加）：
1. **拿下领域内最有影响力的头牌用户**：美食社区电商月 GMV 100 万目标，聊 30 多家零食品牌无人理 → 聚焦良品铺子 2-3 周全力服务、人肉导流开店 → 搞定后中小品牌顺利入驻。
2. **先在细分渠道 / 领域成为头部**：彭小六简书。
3. **先拥有稀缺资源 / 能力，形成角色反转**：供需动态平衡，找当下稀缺侧。喜马拉雅 2015 签阅文集团版权扩内容供给拉开差距；招聘网站每月 BD 一批前端简历，企业须注册上传职位才能看。
- 叠加例：拿下知名服装品牌 + 京东 618 细分品类头部 + 稀缺供给资源。杠杆对执行力要求更高。

### 3.4 三类操盘手规划实例

**① 增长类目标层层精细落地**
- 电商类目半年月收入 5-6 万 → 100 万+：锁定客单价，抓流量和转化率，按月定策略（11 月打 1-3 个爆品月销 30-60；12 月爆款月销 200，转化率锁 1%，日订单 1→28 靠直通车 / 钻展加投；2-3 月冲量，转化率 1.1→1.3→1.6 靠清仓 / 团购活动，客单价降但算得平）。
- 化妆品店年 900 万：按 Q 拆（Q1 日销 4600 / UV 1900，找主推品、打磨体验品引流 + 月度主题活动；Q2 日销 2 万 / UV 5000，找符合定位的爆品；Q3 主推热卖特惠套装拉客单价；Q4 爆款 + 活动 + 套装）。
- **优秀规划三要素**：明确的目标拆解逻辑 + 每个重要目标有明确抓手 + 表达对象清晰。

**② 多战线方向性目标（"一年内成为品类第一"）**
1. 先定义"第一" = 产品体系最全 / 订单吞吐最大 / 口碑最好 / 行业权威背书
2. 区分进攻叠加（订单 / 用户规模）与前提保障（其余三项）+ 约束（时间 1 年，资源可提）
3. SMART 化：学科地图下 15 门课 / NPS ≥60% / 每月 10 万订单 / 5 个头部 KOL + 5 家公司背书
4. 排先后：口碑和课程体系先发生（收入保障），背书可靠后；订单 = SKU × 渠道 × 转化
5. 找最优路径加杠杆：搞定明星用户 / 老师背书；先做一堂爆款课拥有头部效应；优先生产大家想要但稀缺的课程话题

**③ 独立负责一条业务线自己定目标**
先判断业务阶段（早期验证需求交付 / 有模型要标准化规模化 / 模型稳定加速增长）→ 四层问题：

| 问题 | 动作 | 案例（历史人文地理短视频 APP，A 轮 150 人，15 人团队，3000 条免费短视频 + 付费专辑） |
|---|---|---|
| 这事能做多大 | 全局方向性思考 | 看出版行业存量 / 受众；看得到 / 喜马拉雅 / 知乎同板块数据；参照得到"垂类大咖一月 3 次上新"推演 → 月活 50 万 |
| 怎么才能做这么大 | 找同类模型 | 持续免费 IP 话题上新 / 系列连载黏住 / 大量免费内容 + 分类索引消费路径 → 选后者 |
| 真的能做到吗 | 验证 | 一条短视频生产 10 天，供给可依赖？看过 5 条以上免费内容的用户留存高 20% → 算账 3000→3 万条 |
| 怎么做到 | 执行 | 提免费内容供给效率 + 外部采购；用户引导按消费路径走 + 激励 |

AB 类操盘手先保证做好后两件，理解前两件逻辑。

## 4. 进度管理两种方式

| 方式 | 逻辑 | 要求 | 适用 |
|---|---|---|---|
| 瀑布流式 | 一环扣一环（需求分析 → 架构 → 文档 → 详细设计 → 代码 → 测试 → 上线） | 提前把所有事的关系逻辑要点想清楚；风险预案只能 A 出问题用 B，B 不奏效无解 | 路径明确、有经验的项目；强约束强考核强跟进 |
| 敏捷动态演化式（Scrum） | 承认想不清楚先干；leader 维护动态需求池（老板 / 自己 / 用户）→ 每周冲刺回顾更新需求池 → 每日站会同步；看板 | 成员自主能动、拥抱变化；leader 能快速定义问题、快速反馈调整迭代 | 探索型项目 |
