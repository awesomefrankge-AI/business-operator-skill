# 常见业务模型分类库 + 跨界借鉴方法

来源：课程第三章第 4 节。用于：用户"见识少"、不知道有哪些可借鉴的模型、想从其他行业找解法。也是探索型项目第一步（形成业务模型层面的价值假设）的检索框架。

---

## 1. 跨界借鉴的基本思路

```
负责独立业务模块
  → ① 检索高度相似的行业 + 相似的业务模块
       行业：教育 / 金融 / 医疗 / 文娱 / 零售电商 / 游戏 / 出行 / 服务业 …
       模块：增长获客 / 渠道代理商管理 / 供应链 / 留存促活 / 服务交付 / 销售转化 …
       → 能解决 → 直接学习借鉴
  → ② 不能完全解决 → 定义"我要解决的问题的性质"
       → 检索具有相似性的同类问题在其他公司怎么解决
         例：大客户管理 → 线下精英圈子如何维护
             维护几万 HR → 批量用户关系维护
             品类运营培养 → 特定岗位人才培养（EDAC）
  → ③ 自己过滤取舍，结合现状部分借鉴 → 跑
```

### 案例
- **三节课助教运营**：问题本质 = 教学管理 + 教师培养培训 → 看教育公司对应模块 → 剩余问题再定义：众包管理 / 供应链管理 / 服务品控 / 用户激励体系 / 优质社交圈层维系 → 分别找参照。
- **Airbnb 房东运营**：相似行业 = 房地产中介（业主管理：签约 / 持续沟通 / 维系 / 房源稳定 / 风险预防）+ 酒店管理（服务交付标准 → 要求房东）→ 剩余问题：房东社群运营 / 用户激励体系（部分房东参与经营服务）/ 供应链管理（房源分类支撑前端增长）。

### 反面：K12 英语外教一对一（跨界借鉴的坑）
问题：外教教学服务不稳定。错误做法：直接进细节（量化评价 / 阈值 3 分 / 教学 SOP）+ 散乱借鉴酒店 / 滴滴司机 / 家庭保姆 → 一堆信息无法判断适不适用。根因：**没定义问题实质、没明确需要什么样的模型就进入细节。**

正确三步：
1. **明确问题实质**：交付 = 给用户一个稳定预期和成果。
2. **看同行业同问题的答案**：教育交付分 **目标导向型**（四六级 / CPA / 托福，通过考试拿证书 = 交付完成）vs **体验保障型**（商学院社交，不承诺结果但节点体验超棒）→ 该产品属体验保障型（外教陪玩，以英语为介质，语言提升无法评估）→ 梳理用户体验地图（峰值 / 终值 / 低谷、曲线形态、每节点靠社交互动 / 内容 / 特殊服务 / 激励支撑）→ 与同属体验保障型的教育公司对比借鉴。
3. **跨领域借鉴必须按核心受众和产品属性找相似度高的成熟业务**：

| 产品属性 | 可借鉴领域 |
|---|---|
| 使用者与付费者分离、同属一个家庭 | 老人看护服务 |
| 高客单价、亲子需求 | 亲子营地教育 |
| 一对一且排他 | 医院一对一陪护 |
| Quality time 式在线互动 | 在线主播调动互动的手段 |

深刻理解业务需要时间和大量实践，不要速成。

## 2. 常见业务模型分类框架

业务模块：**增长**（外部获客 / 单体用户价值放大）+ **交付保障**（生产 / 交付 / 供给流通）。不穷尽，自行往框架里填新模型。

### 2.1 增长获客模型（都基于营销转化漏斗，驱动方式不同）

| 驱动模型 | 逻辑 | 适用 / 案例 |
|---|---|---|
| 话题内容流量驱动 | 好话题 + 对的人 → 内容（观点 / 洞见 / 段子）→ 分发（用户自发 + 官方）→ 引流转化；需内容生成机制（先话题再找人提问 / 给用户工具 100 人聊出 3 条爆款筛选） | 社区 / 内容产品 |
| 品牌 PR 驱动 | 用品牌占据心智，用户搜索直接搜品牌名 = 天然流量入口 | **低频但靠大流量盈利**的业务：58 同城（杨幂地铁广告 + 姚劲波上节目）、拉勾（总理喝咖啡 / 大咖专访 / 联合抢人）。变体：每波投放配一波品牌 PR，监测获客成本是否因品牌下降 → 品牌工作价值可评估 |
| 产品体验 / 功能驱动 | 找用户使用中有社交分享动机的场景 → 设计社交介质促成分享 | 网易云音乐"地点 + 歌手故事"推荐 |
| 社交关系链驱动 | 三级分销 / 裂变分享，利益机制 / 权益捆绑 | 拼多多拼团 |
| （补充）持续上新 vs 单品长周期 | 售卖生命周期短 → 海量上新驱动；长 → 稳定链条 + 用户增长驱动 | 见 02 参考 T1 |

### 2.2 单体用户价值放大模型（留存 / 活跃 / LTV）

| 模型 | 适用 |
|---|---|
| 用户生命周期 + 典型路径模型 | 少量用户 / 产品线少 |
| 留存模型：关系（缔结更多有效关系 / 互动）、内容（优质内容推送匹配）、功能（找到留存功能点，引导强化补贴） | 有关系 / 有内容 / 有功能的产品 |
| 用户分层运营：用户金字塔 / AARRR / RFM | 海量用户多产品线 |
| 用户成长体系：荣誉身份 / 权益 / 竞争激励 / 等级；电商会员促复购 | — |

### 2.3 交付保障模型

**生产**
| 模型 | 要点 |
|---|---|
| 单线流程式 | 传统制造 + 配套管理机制 / 系统 |
| UGC 组织式 | 海量用户分层定向引导 + 激励（物质 / 精神）+ 反馈 → 海量内容筛选过滤优质 |
| PGC | 作者管理（约束 / 激励 / 监督）+ 生产要素库提效 + 标准化流程 |

**交付**
| 模型 | 要点 | 案例 |
|---|---|---|
| 目标达成式 | 把达成过程分解成步骤，每步的机制和角色 | toB 客户成功项目上线；三节课课程：培养目标 → 岗位任务拆分 → 章节目标重难点 → 训练方式 → 分层教学路径 → 数据监控策略调整（劝退） |
| 体验保障式 | 明确界定用户在哪些节点得到什么体验 + 背后监测体系 | 五星酒店拎包 / 房间灯光 / 前台微笑；4S 店售后：准时交车率 / 外返率 / 内返率 / 技师生产率 / 备件满足率 |

**供给流通**
| 模型 | 要点 |
|---|---|
| 内容生产分发模型 | 单篇组织展现 → 专题 → 索引分类标签 → 全站展现 → 对外分发，每模块建机制 |
| SCOR 供应链 | 三层：关键指标（反应速度 / 成本 / 资产利用率）→ 计划 / 采购 / 生产 / 配送 / 退货五六环节 26 套标准流程 → 每流程输入 / 要素 / 输出衔接 |
| QR 快速反应 | 多品类小批量买方市场，备生产要素不备成品（戴尔直销） |
| 餐饮供应链四类 | 单店采购 / 集采集送 / 集采分送 / 中央厨房标准化 |

## 3. 小结
先定义问题 → 成熟行业找相似模块 / 运营体系 → 研究 → 结合现状部分借鉴 → 跑。只看不干没用，必须有真枪实干跑通模型的能力。
