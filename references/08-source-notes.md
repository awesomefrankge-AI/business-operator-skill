## 导论
- 4 特质：着眼外部·杀伐决断 / 运筹帷幄·建立+撬动放大模型 / 使命必达·强力破局·化不可能为可能 / 建精锐之师
- ABC 三层：A 大公司项目leader；B 小公司部门负责人；C 大公司独立业务线负责人/创业者。先AB后C
- 企业经营链条：战略&商业模式 → 整体/局部业务模型 → 业务规划&目标 → 执行落地。多数人只在执行层
- 执行者 vs 操盘手：等靠要 vs 上级给命题、我给答案给结果
- AB 四胜任力：承上启下拆目标独立规划 / 上级抛问题能对话给答案 / 突击队解决复杂问题 / 带出可依赖队伍
- 5 障碍：思考不同频 / 规划不靠谱不简单不明确(什么都看=什么都没看) / 见识少方案在小圈子打转 / 管理不到位 / 业务不精深无法指导
- 成长路径：前提(技能过硬、3年+、素养) → 底层认知(商业思维/业务模型/复杂问题拆解) → 4 深层能力(理解高层决策/工作规划/探索破局/团队管理) → C类附加(体感判断、人脉、行业洞察，靠积累)
- 边界：非市场化/关系导向行业不适用；不要幻想速成；50→70 可以，30→80 不行
- 案例：电子烟禁令30天开100家线下店，同时验证自营/品牌合作两种模型

## 第一章 高层同频
### 1.1 CEO视角操盘
- 经营管理链条 5 层：战略&商业模型 → 整体业务模型 → 局部业务模型 → 各战线规划&目标 → 执行落地
- CEO 第一人称工作法：①内外获取信息评估战略方向(何时进入什么市场、机会) ②明确战略落地框架(从哪些地区/产品/服务形态起步) ③界定重要战线+落地策略(优先打哪类人群/哪种模式) ④定目标做规划(基于假设和参照；备兜底C方案) ⑤执行到位再复盘调整
- 前三步核心动作：向外看市场动态 + 不断输入/评估各种模型，选更有利可依赖的模型；第③步要找出局部战线的假想获胜逻辑
- 动态思维 vs 静态思维：操盘手必须动态看经营问题（市场/用户/竞争/技术变化），执行者要确定性=静态、等靠要。市场变化越快、业务越不成型，调整越要敏捷
- 老板善变：部分是没想清楚，更多是市场倒逼
- 案例西贝2020疫情：堂食48亿/外卖8.8亿，原目标+15-20%；2天内筛门店(43正常/192只外卖/132关)、改菜单推家庭套餐、后厨转运力、安心卡。= 高层重评→推翻规划→主推外卖→倒推策略目标
- 案例新东方：收入+30%利润-20% → 业务层拆分(线上/线下→K12/留学/大学/少儿→少儿下沉市场只+30% vs 竞品+300%) + 财务层拆分(各线成本结构→少儿营销成本+300%收入+30%) → 找负责人要解释。成熟赛道必须用模型(最终落到数据指标)评估管理驱动业务
- CEO 向外看(市场变化/空间/机会) + 向内看(经营逻辑评估业务模型找问题)，按外部变化快慢和业务成型程度动态调整
### 1.2 评估公司价值
- 投资人/CEO 看两件事：当下挣钱能力 + 成长性，都需要模型
- 流程：业务假设 → 收入公式/模型 → 提数据验证假设 → 预测模型 → 估值/判断
- 教育公司例：收入 = Σ课程(月开班数×满班率×可售卖生命周期×客单价)；公式拉出来，增长发力点(课程数/开班频次/满班率/客单价/生命周期)就清楚；核心验证数据=每次开课用户数增幅(验证口碑老带新假设)
- 本质：锁定商业价值C，倒推 A→B→C 的模型链；把经营管理逐步模型化
### 1.3 三大模型
- 商业模式：面向什么市场(toB/toC/toG)、提供什么产品/服务、怎么销售、如何获利 → 决定基本收入公式
  - 互联网4种：①流量+广告(收入=广告流量×点击率×单次点击价) ②多边平台+抽佣(GMV×佣金率) ③产供销(流量×转化率×客单价) ④免费+增值服务
- 商业经营模型=财务模型：收入-成本=利润；哪些部门产利润、哪些是成本；监测利润结构/成本结构，优化(成本部门提效降本，利润部门放大)
- 业务模型：业务如何运转的具体链条/环节；分全局(驱动收入增长)与局部(某模块，如教学效果保障链条)；评估链条标准/稳定/可靠否
- 例：B2B获客漏斗 线索发现→关注兴趣→信息收集→官网线索转化→销售跟进成单
### 2.0 六类难点
1 老板现阶段关注什么 2 决策判断不同频 3 老板抛问题想要什么层次答案 4 如何评估/证明工作价值(涨粉10万老板不在乎) 5 流程机制要不要有 6 直接老板是中层
### 2.1 老板现阶段关注什么（生命周期）
- 并非每家公司一开始就有模型。早期=打井：N个方向同时试，哪出水就加投(三节课2016)；成熟期=以商业价值为核心、模型驱动
- 投资人/管理者评估：早期公司只看"有没有做大的可能性"(怎么找不重要)；成熟公司看模型(增速/盈利)
- 生命周期×融资轮次：初创/引入期 → 增长+破局就是一切；A轮前后 → 必须关注商业能力变现盈利，开始构建业务模型并以模型组织团队资源；B轮后 → 放大模型；旧模型只能1倍增长想要10倍→升级模型找更有前途的模型(滴滴接管司机供给推快车专车)
### 2.2 决策判断同频：4 个决策工具（按决策结构：判断赛道→战术打法→风险防范&机会管理）
1. 线性 vs 非线性(指数)增长模型：边际成本能否趋零/聚集效应强→指数(社交/在线工具/娱乐平台/关系链裂变/拼团)；toB销售驱动/线下零售/线下教育→线性(堆人力)。私域=线性玩法：堆人力、难几何级放大。生态型平台(微信/小红书/快手)也遵循指数生命周期→判断所在平台处于哪个阶段还有没有红利；判断当前增长引擎处于什么周期，到末端就要开辟新引擎
2. 成本收益模型：任何事/需求/活动/人都回到 投入成本(时间金钱资源)vs预期收益vs收益对当前是否重要；能估出团队每人/自己时间值多少钱；跟老板沟通讲成本收益最高效
3. 头部效应模型：头部收益是腰尾部几十上百倍。彭小六案例：微信写不过→退到简书(只有一个对手)→对手3天1篇他1天3篇+同话题换角度+@人→4-5个月超过+3个月巩固→"简书一哥"势能反哺微信/电视台/出版。两条：任何赛道成为头部是较优策略；一线战场成不了头部→退回二线战场成头部再携势能杀回。应用：10个渠道铺 vs 一个渠道打爆；小公司核心角色 vs 大公司边缘执行
4. 杠铃策略+黑天鹅策略：80%+资源给确定性主战场保核心目标，≤20%给高不确定但可能颠覆/成为3年后增长引擎的探索；前提资源有一定充裕(20-30人)；例10人8做公众号2做快手，2-3个月review出水加投不出水砍。一线执行必须使命必达，否则反馈无法支撑高层决策
- 第一章前半总结：到一定阶段一切模型化，用模型和数字跟高层对话最经济
### 2.2.1 加餐 管理有多复杂
- 下沉市场"穷人版MUJI"案例：选址/选品/供应链/营销一环扣一环牵一发动全身；服装SKU库存压力→换标品；下沉用户认熟人不认品牌；能力很强仍失败
- 忠告：初级操盘手别奢望掌控全局；合理预期=支持一个比你强的人掌控全局，用执行帮他验证模型；战略级决策99%的3-5年执行者触及不了
### 2.3 老板抛问题想要什么答案：5 层逻辑思考层次
"不怕老板不干活，只怕老板有想法"。同一个问题在不同日子背后需求可能不同。留学咨询众包海外留学生做老师案例
1. 验证战略方向假设 → 给：需求成立否、可行性分析、供需两端调研、往哪个方向更靠谱（需求侧用户关注1234海外留学生能解2点其余需自营补；供给侧8.5万留学生北美集中欧洲分散；付费意愿）
2. 评估商业模式/成本模型 → 给：基于假设的财务/成本估算、对现有业务模型的影响（1兼职服务5人付3000→成本结构变化；引入兼职需品控/培训升级否则撑不住）
3. 了解业务模型分支模块怎么搭 → 给：该模块整体模型+重点难点（招聘→培训→运营管理→品控；品控是关键：监测什么/怎么评估/不合格怎么办）
4. 了解执行落地路径 → 给：计划、里程碑、时间、需要的资源、承诺结果（先A再B再C，2个月，需X资源）
5. 讨论某件事怎么执行更好 → 给：3种思路ABC，我认为B更高效，请确认
### 2.4 工作价值评估
- 业务成立三前提(树)：商业价值成立 = 用户价值成立(用户/需求/场景) + 保证稳定交付(生产/供给流通/服务交付)；价值放大(流量/增长/销售成交)。三问：用户价值成立吗？可被稳定交付吗？增长可被放大吗？→ 再问如何提升经营效率
- 生命周期关注点细化：初创=增长破局怎么搞都行 → 有流量收入后=需求是否批量稳定存在、交付能否稳定(只有标品才可规模化) → A轮=形成可规模化能算账的增长业务模型 → 模型稳定后=营销/交付/供给持续降本提效 → B轮后=模型是否需升级换更大想象空间
- 高层眼中有价值的4类成果(过程不算)：①提升效率降低成本 ②稳定了某个重要交付 ③放大了收入 ④创造了有商业想象力的新产品(如快速搞出几十万私域流量池)
- 按公司类型：
  - 早期公司：为增长破局贡献价值(社群裂变十几万粉/玩法让DAU几千→二三十万) 或 为稳定存在的需求找到可规模化解决方案(先卖100万/找到半年内可规模化驱动的打法)
  - 成熟公司新业务：快速证明/证伪高层的想法(板上钉钉yes/no) 或 在战略框架和优势资源内定义更大想象力的需求/解决方案 或 对现有需求找到效率更高的可规模化方案
  - 成熟公司成熟业务：只看挣钱能力。收入-成本=利润下沉到部门 → 成本中心(不直接面向市场；管理要点=保障链条稳定运转同时降本提效) vs 利润中心(直接面向市场带来收入/增长；要点=更高效率挣更多钱/流量)
  - 制造业：生产(生产/工程/品控/采购/PMC)+流通(仓储/运输配送)=成本中心，销售(渠道/市场)=利润中心；服务业：交付团队/IT研发=成本中心，营销获客(门店运营/会员运营/销售转化/市场线索)=利润中心；互联网重业务型(在线教育)：教研/教学/产研=成本中心(产研提供工具系统提升前端效率)，营销=利润中心；互联网产品即业务型(内容/工具/娱乐)：产品体验驱动增长，产品经理是业务人员对业务指标负责，研发/设计/职能在下层
- 自评：判断自己在成本中心还是利润中心；证明方式：某块收入没有我的支持不可能发生/因我被放大；降低了某块巨大成本；5个人的事我1人干完
- 指标两类：业务项(收入/ROI/CAC/完课率/满意度/NPS/用户增长/留存) 效率项(人效比/人均单产/坪效)；HR人效例(200人配10HR vs 150人配3HR)；咨询公司人均产值150-200万参照
- 提醒：业务部门内部也是层层嵌套的小模型(体验课：先让链条稳定转化，再放大效率如销售人均单产)
- 自我价值评估两类：凭经验手感(需老板信任/过往成就) vs 数据模型(绝大多数人走这条)
### 2.5 流程机制要不要有
- 本质=提升效率。成熟公司管理必含系统模型+流程制度；前提是商业逻辑和业务模型定型；模型没定型时一切灵活为业务让路，不需要多流程
- 成熟公司工作机制：战略方向框架→业务模型定型/变更→组织架构资源分配→各部门工作。配套：对事(知识管理/赋能系统、战略与经营回顾机制按周月季、战略协同系统保部门目标不打架、绩效目标管理) 对人(选拔淘汰、盘点轮岗、激励晋升)
- 上层模型变了流程也要变；业务越成熟公司越大配套越庞大(华为例)；成熟公司某些机制不可动摇(腾讯晋升机制)；管理服务于业务；当下阶段只需理解意义+初步应用工具
### 2.6 直接老板是中层
- 互提要求：他给你负责的问题/部门对公司的价值/目标指令，给不了就向他要；你给答案。辅助判断他的规划与高层是否偏差，帮他搞定信息不对称
- 忠告：先支持老板更好思考判断，保证优质决策落地；老板错了用行动快速证明；起点=参与到老板的决策过程，不是替代老板。不追求绝对正确答案，以商业逻辑为导向迭代求更优解

## 第二章 业务模型（课程灵魂）
### 导读+1 三大模型关系
- 操盘手第一要求：把业务经营管理模型化——公司管理=一个公式，管理=控制公式里的变量
- 中早期公司：自下而上，先跑业务模型(先在某件事上创造商业价值→看能否标准化→可规模化)，再推演出经营模型和商业模式；老板脑中利润成本零散粗放
- 成熟公司：自上而下，商业模式和经营模型稳定，高层守住上面，往下优化/升级业务模型；不容许背道而驰的事(不如出去创业我投你)
- 层级视角(成熟公司)：高层看商业模式+经营模型+整体业务模型(最多到局部)；中层看整体业务模型/局部业务模型/目标规划，交付模型跟老板同频；执行层执行
- AB类操盘手职责：成熟公司=理解全局业务模型(至少商业价值增长模型长什么样)+搞清自己负责板块的局部业务模型+往下定目标规划；中早期=一线执行破局+抽象出业务模型跟上级对话辅助动态决策
### 2.1 业务与业务模型定义
- 业务 = 能独立产生商业价值的经营单元：产品/服务是什么、用户是谁、通过什么渠道触达、产出什么商业价值
- 业务模型 = 稳定 input → 一套有逻辑的体系(规则/协作机制/业务流程) → 稳定 output；服务于商业模式，让业务可规模化。给我A，一定给你B
- 意义：进入任何业务已成型的公司，脑中要有整体业务模型+自己负责局部业务模型的清晰认知/假设
### 2.2 全局业务模型构成
- 两层(+底层)：①整体业务增长模型(收入/商业价值产生和持续增长的链条：流量→付费→复购) ②生产供给交付保障体系(生产研发流程/供应链管理/交付服务保障，与上层一一对应) ③基础工具&效率系统(在线学习系统/教务系统/大公司中台)
- 实质：input(钱+基本生产资料) → 运营体系 → 更大收益
- 增长模型是重中之重，决定收入公式；"流量→转化→付费"三个框没有价值，必须细到具体渠道/产品线/收入来源
- 案例长租公寓：线索3渠道(房源平台投放/在线社群/沉默老用户外呼)→到店看房→3类房源(促销特价/品牌整租/低价整租)→签约付费→续租+在住增值消费(金融/到家/会员/电商)；下层房东BD供应链、租客服务保障
  - 收入公式：①(投放线索+社群线索+召回线索)×到店看房转化率×平均租住周期×月租均价 ②老用户总数×续租率×平均租住周期×月租均价 ③在住其他消费
- 前提：业务相对成型；梳理必须足够细
### 2.3 梳理方法 = 1个基本逻辑 + 4个问题 + 3个额外思考
**1 基本逻辑**：按商业模式画出典型商业价值诞生路径/收入转化链条雏形，再落实到具体产品功能和用户路径
- 流量+广告：获流量→维系留存放大 ‖ 找广告主/线索→销售转化→变现
- 平台+抽佣：C端/需求端流量 + B端/供给端资源 → 平台运营规则撮合交易→抽佣 → C端复购/B端留存
- 产供销：流量获客→转化路径→付费→复购(单一复购玩法 或 LTV/生命周期运营体系)
- 免费+增值：流量→免费产品注册使用→持续使用运营→用户分层→部分增值付费
- 案例：房产交易平台(C端 PR/效果广告/线下/小程序→用户分层引导→二手房/新房/租赁/海外业务线→线上/线下转化→成交；B端 拓展→邀请入驻→标准化培训→承接商机)；健身教育平台；游戏平台(买量→下载→注册→新手引导→次留→首充破冰→分层+成长体系→持续付费)
- 商业模式大同小异，业务模型各不相同
**4 个问题**
1. 是否对不同用户/渠道存在不同的稳定转化路径？有→把每条能独立稳定形成通路的路径单列为独立增长引擎(健身平台：投放留表单电话触达/社区免费低价培训/高校公开课)。不必穷尽，只列稳定持续的
2. 核心产品是否重决策/非标/高价(买房/高价课/企业采购系统/咨询)？是→链条必须加体验产品或辅助决策型产品(测评/主题看房/公开课)，把流量引到体验产品
3. 产品线是否多元/SKU多？单一→转化路径尽量单一简单易驱动；多→必须给产品分类+理清关系(入口产品/分流逻辑/复购成长路径)或干脆拆成独立业务模型独立团队，否则各产品线抢流量无法决策。电商案例三类：爆款(低价走量每月几万单)→利润产品(爆款带货复购引导)→防御型/附加产品(手机壳贴膜，留住消费习惯)；策略=4渠道流量集中导爆款1/2
4. 是否需要长期用户生命周期管理？短(托福雅思)→单线程路径(导入→注册试听→首购→二次附加→流失)；长(懂球帝2-3年)→注册使用后必须有用户分层+长期维系体系(游戏：免费/小额/中额/大额分层+每层权益策略)
**3 个额外思考**
1. 单一产品售卖生命周期长短？短(≤6个月，知识付费/快消/出版/饮品/数码/保健品/部分社交APP)→增长靠海量上新/SKU增加/快速迭代，模型需海量选题上新生产逻辑；长(4-5年，教育/医疗/金融/大宗消费)→靠稳定转化链条+稳定交付+用户增长驱动。三节课研究100+课程：主打大IP/话题的课→用户预期离散→无口碑→6个月内90%收入；目标人群和教学目标明确的课→口碑→卖5年逐年涨(50万→100万→三四百万→六七百万)
2. 是否需持续搞定稀缺资源驱动增长？是→围绕稀缺资源BD和运营单独构建体系作为增长引擎(会展公司收入=搞定几家行业协会/头部媒体；2014 IT招聘BD前端工程师简历每月三五百份→流量和企业注册涨)
3. 增长是否受供应链制约？是→下层必须有强供应链管理体系与营销增长联动(教育3个老师×200人/班=月上限400单且要保满班率≥80%排班与售卖联动；酒旅房源/电商SKU库存/滴滴运力；房产平台按城市扩张需供给基数+质量+稀缺房源，房源体系/客源体系/B端激励分佣体系)
### 2.3.4 案例串讲 (1+4+3 应用)
- Airbnb：平台抽佣雏形(C端线索获取转化付费 / B端房源拓展入库维护 / 平台匹配撮合)→Q1一线用户(风格装修主题)与三四线用户(价格)分两条路径→Q2住宿较标准不加→Q3房源多分A类(一线易转)B类(三四线易转)，房源拓展入库维护下沉为供应链体系→Q4出行一年4-5次需长期管理→会员运营体系提LTV→T1房源生命周期长不需上新→T2三四线优质高性价比稀缺房源→单独拓展运营体系→T3每开一城需供应链配合+地区订单需求平衡
- 小红书(只看社区)：流量生意(外部渠道→注册→留存活跃)→Q1 KOL vs 普通用户互为供需、一二线vs三四五线话题不同分开→Q2否→Q3功能多需梳理用户成长路径/引流功能/进来后往哪走→Q4需要分层精细化运营→T1否→T2 KOL/好话题/好内容是稀缺资源需配套运营机制→T3否
- 跟谁学高途(K12小班直播)：线索→试听体验课→付费→续费→Q1一线/三四线分开→Q2高价非标必须体验课→Q3课程多但一年级续到六年级逻辑简单→Q4需长期管理→T1长→T2老师非名师不算稀缺→T3小班5人老师资源浪费，必须师资班期与前端流量联动
### 2.4 局部业务模型
- = 全局模型中某一核心环节/模块单拿出来；处于链条某一环，需明确上下游、资源投入和目标、与哪些业务方对接联动；是完整商业系统的子系统
- input(特定业务资源/人/钱/生产资料) → output(稳定标准的业务价值：某环节转化率/满意度/人效/收入)
- 案例樊登读书会城市合伙人：省分会(官方给渠道发展扶持政策资源)→城市分会→县区分会(配樊登书店实体承载活动)→企业分会(小驿站)，三级分销利益分成，以省为中心；input人力和钱，output稳定会员增长
- 4 要素：流程、SOP、约束机制(利益分配/激励/品控/考核)、角色分工
- 梳理4步：①明确input/output ②output主要靠流程保障还是靠分工协作机制保障 ③先搭业务流程(三节课班期教学)或先搭角色分工(樊登) ④补配套约束机制(激励/品控/考核/SOP)
- 两类常见局部模型：增长导向(input流量/钱/资源→output订单/新增用户/收入，如toB会销每场会议)；生产交付保障(input生产资料/初始状态用户→output成品/高满意度/续费)
- 简单业务：流程画出来就七八成(三节课魔鬼训练营：讲师BD→课程研发[立项评审→大纲→PPT录制]→班期教学[开营→每周看课→作业→毕业设计反馈]，补每周看什么数据调什么策略)
- 复杂业务=角色多/用户类型多：先界定input/output→列出角色及关系分工→再串协作流程和各角色策略(教育平台个性化辅导：running partner/教研/助教/班主任×学前学中学后；美团用户分层：按历史订单数×最近购买时间分十几类，每类定义+策略，类之间不需发生关系，后端再补部门协作流程)
### 2.5 总结与提醒
- 评估业务模型好坏两问：①input/output稳不稳定、能不能规模化——不能规模化的模型毫无价值(只有我能写爆款文案≠模型) ②在行业内是否有强竞争力和增长驱动力：有无壁垒/独特优势；收入公式清晰否、易驱动否(需20件事同时发生=难驱动；一个地区一套打法每次100万一年50次=5000万，清晰易驱动易定位问题)
- 意义：早期业务=搞清要奔跑验证依赖的模型是什么+当下最重要假设是什么；成熟业务=搞清该关注什么信息、贡献什么价值才不跑偏
- 4 个跑偏反面：toB公司新媒体10万粉20篇10万+与企业线索无关；AB轮公司品牌部大咖活动事件营销讲不清对主业价值；社区运营总监拍脑袋全国粉丝会几百个群五六人四五个月无关内容/流量/留存被干掉；百度2013-14做教育(教研教学交付基因≠流量基因，是开辟新基因非放大已有基因)失败
- 忠告：早期公司=边干边动态完善模型，跑通后定型规模化放大；成熟公司=所有工作不能逆现有业务模型而行，要么借助其核心资源要么为它服务(更强健/规模/效率)
- 组织结构调整服务于业务模型放大或升级；选了模型必须有匹配的组织架构。三节课2019：旧模型(按市场热点话题策划选品+单课营销)→渠道市场部/品类运营部/教学服务部；新模型(社群体验小课集中转化少量几类课)→营销中心(渠道→小课→转化，对订单收入满班率负责)/学习中心(研发交付稳定、教学目标口碑、给营销弹药)。阿里约每半年调一次组织结构

## 第三章 业务模型巩固篇
### 3.1 局部模型如何成型（三节课B端案例，历时1年+）
- 2017 随机零散：大厂找上门，来一个接一个不主动找；交付完全靠CEO个人临场发挥→前端获客不稳、后端交付不稳
- 中期：搭销售转化雏形(人肉BD+买少量企业线索+招聘网站合作找培训负责人→10人销售团队定向跟进卖训练营)，有模型但不稳定(不同销售转化率差异大、行业需求不同)
- 交付：一人牵头3-4个月在10家企业落地打磨→输出交付模型(分周期/每周期目标/角色/机制/验收指标)→2018 交付稳定
- 前端优化：加辅助决策/体验产品(HR社群+低客单价体验课)→转化率稳定→业务成型可评估成本收益
- 中早期公司业务初步成型至少小一年
### 3.2 从0搭建模型逻辑（品类运营培养案例）
- 问题：3个品类各需人做策略规划达成收入目标，岗位画像市面没有→"人的培养"命题
- 步骤：①向外找参照(宝洁/阿里 EDAC 模型：Explain 方法教程→Demo 真实示范→Apply 带着练手→Consolidation 独立负责小项目结项巩固) ②拆细岗位工作内容(基础工具方法/常见模块：单班期推广策划、单SKU增长策略、单品类整体增长策略/进阶方法) ③每个模块落到EDAC四格表 ④放几个新人跑1-2个月验证调整 ⑤定型：画像满足3条件→3周上岗
- 逻辑：先找外部模型→再看它能否帮你获得稳定 input/output
### 3.3 忠告
- 简单模型=单线程、变量少、分支少(工具产品)，1个月内能出答案；复杂模型=多线程+N多人与人交互(每个人都是变量)+N多信息交互(A信息制约B行动)，周期长风险大(沃尔玛供应链总部/配送中心/仓库/门店信息流 100年；美团外卖后台运力测算/单量预测/派单/补贴定价；教育教研教学用户互动节点多)
- 复杂业务的公司须：局部有成熟经验可借鉴 或 雄厚资源 或 几个模块已跑稳
- 反面：校园团队转化产品未验证+公号投放+老带新权益(年度4场大咖直播)三件事揉一起→互相影响无法归因(转化率低是产品问题还是投放用户质量还是直播分流？)→没有定量只有变量→一地鸡毛
- 忠告1：新项目搭模型，要么别人跑通过的成熟模型(定量，跑不通就是执行不到位)，要么足够简单单线程变量少快速跑
- 忠告2：没有成功经验和手感，别直接上手搭复杂模型；能搭复杂模型的leader是把过去经验手感当最大定量
### 4 跨界找可借鉴模型
- 基本思路：负责独立业务模块→①检索高度相似的行业(教育/金融/医疗/文娱/零售电商/游戏)和业务模块(增长获客/渠道代理商管理/供应链/留存促活/服务交付/销售转化)→能解决直接学习借鉴→②不能完全解决→定义要解决问题的性质→检索相似性的同类问题在其他公司怎么解决(大客户管理→线下精英圈子维护；维护几万HR→批量用户关系维护；品类运营培养→特定岗位人才培养)
- 案例助教运营：问题本质=教学管理+教师培养培训→看教育公司对应模块→剩余问题再定义：众包管理/供应链管理/服务品控/用户激励体系/优质社交圈层维系→分别找参照，自己过滤取舍
- 案例Airbnb房东运营：相似行业=房地产中介(业主管理：签约/持续沟通/维系/房源稳定/风险预防)+酒店管理(服务交付标准12345要求房东)→剩余问题：房东社群运营/用户激励体系(部分房东参与经营服务)/供应链管理(房源分类支撑前端增长)
- 案例K12英语外教一对一(坑)：问题=外教教学服务不稳定。错误做法：直接进细节(量化评价/阈值3分/教学SOP)+散乱借鉴酒店/滴滴司机/家庭保姆→一堆信息无法判断适不适用。根因：没定义问题实质、没明确需要什么样的模型就进入细节
  - 正确三步：①明确问题实质——交付=给用户一个稳定预期和成果；②看同行业同问题的答案：教育交付分 目标导向型(四六级/CPA/托福，通过考试拿证书=交付完成) vs 体验保障型(商学院社交、不承诺结果但节点体验超棒)→该产品属体验保障型(外教陪玩以英语为介质，语言提升无法评估)→梳理用户体验地图(峰值/终值/低谷、曲线形态、每节点靠社交互动/内容/特殊服务/激励支撑)→与同属体验保障型的教育公司对比借鉴；③跨领域借鉴必须按核心受众和产品属性找相似度高的成熟业务：使用者与付费者分离同属家庭→老人看护服务；高客单价亲子需求→亲子营地教育；一对一且排他→医院一对一陪护；Quality time在线互动→在线主播调动互动的手段
- 深刻理解业务需要时间和大量实践，不要速成
### 4.2 常见可借鉴业务模型分类框架
业务模块：增长(外部获客 / 单体用户价值放大) + 交付保障(生产 / 交付 / 供给流通)
**增长获客**（都基于营销转化漏斗，驱动模型不同）
1. 话题内容流量驱动：好话题+对的人→内容(观点/洞见/段子)→分发(用户自发+官方)→引流转化；需内容生成机制(先话题再找人提问 / 给用户工具100人聊出3条爆款筛选)
2. 品牌PR驱动：适合低频但靠大流量盈利的业务(58同城杨幂地铁广告+姚劲波上节目；拉勾事件营销总理喝咖啡/大咖专访/联合抢人)——用品牌占据心智，用户搜索直接搜品牌名=天然流量入口。变体：每波投放配一波品牌PR，监测获客成本是否因品牌下降(信任降低决策成本)，品牌工作价值可评估
3. 产品体验/功能驱动：找用户使用中有社交分享动机的场景→设计社交介质促成分享(网易云音乐地点+歌手故事推荐)
4. 社交关系链驱动：三级分销/裂变分享，利益机制/权益捆绑
**单体用户价值放大**(留存/活跃/LTV)
1. 用户生命周期+典型路径模型(少量用户/产品线少)
2. 留存模型：关系(缔结更多有效关系/互动)、内容(优质内容推送匹配)、功能(找到留存功能点，引导强化补贴)
3. 用户分层运营(海量用户多产品线)：用户金字塔/AARRR/RFM
4. 用户成长体系：荣誉身份/权益/竞争激励/等级；电商会员促复购
**交付保障**
- 生产：①单线流程式(传统制造+配套机制) ②UGC组织式(海量用户分层定向引导+激励[物质/精神]反馈→海量内容筛选过滤优质) ③PGC(作者管理[约束激励监督]+生产要素库提效+标准化流程)
- 交付：①目标达成式(toB客户成功项目上线；三节课课程教研教学：培养目标→岗位任务拆分→章节目标重难点→训练方式→分层教学路径→数据监控策略调整[劝退]) ②体验保障式(五星酒店拎包/房间灯光/前台微笑；4S店售后：准时交车率/外返率/内返率/技师生产率/备件满足率)
- 供给流通：①内容生产分发模型(单篇组织展现→专题→索引分类标签→全站展现→对外分发) ②供应链 SCOR(三层：关键指标[反应速度/成本/资产利用率]→计划/采购/生产/配送/退货五六环节26套标准流程→每流程输入/要素/输出衔接) ③QR快速反应(多品类小批量买方市场，备生产要素不备成品，戴尔直销) ④餐饮供应链四类：单店采购/集采集送/集采分送/中央厨房标准化
- 小结：先定义问题→成熟行业找相似模块/运营体系→研究→结合现状部分借鉴→跑。只看不干没用，必须有真枪实干跑通模型的能力

## 第四章 局部战场工作规划
### 0 规划与模型的关系
- 规划基础逻辑三步：明确目标→拆解为工作计划→进度管理调整；往前一步=目标从哪来(向上对齐商业经营逻辑和核心业务模型)，往后一步=工作先后节奏向团队表达
- 全局模型三层自上而下梳理：增长导向模型→生产供给交付保障(对应增长链条某环节)→基础工具效率系统
- 业务模型清晰→收入公式精细化→组织结构和职能划分可据此理解。电商例：收入=流量×爆款转化率×利润产品转化率×ARPU，渠道A/B导爆款1、C/D导爆款2各算引擎；团队=流量团队(分渠道)/爆款运营(选品/渠道对接/前后端转化/向利润产品分发策略)
- 跨境电商指标体系：GMV=新用户GMV(新用户数[日均访问×注册转化率]×付费转化率×客单价)+老用户GMV(已购用户数×月活跃率×月购买转化×客单价)→营销团队背访问和注册转化；运营团队背付费转化率(站内活动促销)；品类运营背客单价；会员部门背老用户活跃率
- 交付/供应链部门：收入公式要求交付稳定在什么指标区间、供应链吞吐量/效率→多一层映射
- 商业经营模型→团队是成本中心还是利润中心→背两类指标：业务导向(来自在业务模型中的位置/对转化链条哪部分负责) + 效率导向(来自成本/利润中心属性)
- 案例三节课B端：目标3倍增长+盈利。收入=线索×转化率(社群/低价品→训练营两重)×客单价；利润=销售额-销售成本-交付成本-其他。增长团队：3倍来自提线索量/转化率/客单价/续费哪个更有空间；交付团队：支撑客单价提升(1万→5万)+卡交付成本不超客单价X%(死线)+保稳定前提下提效(1人月服务2家→5家)
- 案例K12外教：目标GMV+50% ROI+15%。收入=渠道1流量×转化+渠道2流量×转化)×(客单价+续费收入 或 LTV；公式形态对应团队分工：首付/续费两团队 vs 一个团队管全生命周期)。增长侧：降获客成本/提客单价/提转化率/扩流量；供给侧：扩外教数量/提供应链响应效率/保质前提下提外教服务学员数/提班主任服务效率
- 案例电商线上线下：目标线上3倍。收入=流量×转化×ARPU；利润=销售额-销售-生产-供应链-线下门店-其他。增长侧：扩线上渠道/加强线下门店导流/提转化/提复购；供给侧：供应链响应/降仓储运输成本/选品/线上线下数据打通→个性化推荐→转化率
- AB类操盘手规划基础逻辑：充分理解高层战略+整体业务模型+经营逻辑(理解不决策)→明确局部现状和局部业务模型→据其状态属性定目标规划
- 应有心态：战略方向讨论上给高层提供有效信息；全局业务模型梳理判断上参与部分讨论；局部业务模型上——上层明确要我达成目标/提升指标，或上层给方向要我验证答案/探索可依赖可规模化模型
- 所有信息回归到模型上思考
### 1 合理制定局部业务目标（三要求：不跑偏 / 清晰可衡量可验收 / 与协作部门对齐）
**1.1 不跑偏 — 自上而下拆解**
- 公司战略目标→核心业务/财务指标→各部门目标→二级/三级子目标(目标管理框架)
- 拆解两角度：①前提保障性条件(必要条件：销售招聘到位、新交易系统上线、APP闪退率控制)——要对齐时间节奏(20个销售1个月内到岗→向HR提需求) ②进攻叠加性目标(充分条件：目标具化为数字，怎么叠加达成)。苹果例：钱是必要条件，A渠道5吨+B4吨+C1吨是充分条件
- 数字拆解三法：加法(按渠道/按产品：1000万=A渠道+B渠道+C渠道；新媒体涨粉=自然涨粉+内容涨粉+活动涨粉[裂变/大号互推/H5/投放])；乘法(按路径漏斗：GMV=流量×转化率×客单价；三节课=渠道流量×到体验小课转化率×到课程转化率×课单价)；典型代表式(抓大放小：50渠道×20SKU太复杂→找占比最大的A渠道+B/C产品，数千万用户级公司尤其要用)
- 实践中多逻辑复合：三节课GMV=(渠道A+B+C+D)×小课转化率×(操盘手转化率×客单价+新人起航转化率×客单价)；滴滴 B=C：司机端订单=Σ各产品线(激活司机数×首单率×在线率×抢单成功率×人均完成单)，乘客端=注册用户×首单率×日活率×人均订单×应答率×完成率；管理逻辑=先预测C端总单量→分解到专车/快车/顺风车→看司机端供给对不对得上→对不上开源→看哪条线哪个因子最有放大空间
- 向上对齐：搞清我的工作对上级是前提保障还是直接背他核心指标的一部分；向下清晰：我的目标需要什么前提保障、数字如何拆(加/乘/混合)
**1.2 清晰可衡量可验收 — 局部战场四类目标**
1. 核心业务指标提升/降低X%或稳定在范围内(来自业务模型/经营公式/交付目标推导；最常见)。例健身教育平台营销部关注免费课→线索转化率/预约率/到课率/转介绍率/二次培训率；民宿平台B端产品团队：B端产品→降房东问询量省客服成本+商业化工具提房源转化率；内部效率工具→单销售覆盖5→15房东提人均单产
2. 做一件事实现重要短期阶段性效果(骚扰竞争对手抬高其成本/为PR加势能/融资PR，来自老板短期需求，不一定与模型相关)——要点：搞清达成什么效果+怎么衡量；效果可以问老板，衡量方式必须自己拿选项去确认(融资PR→对投资人PR→覆盖50%以上顶级机构核心决策者且反馈正向)。老板可能说"看我感觉"
3. 验证型：验证模型OK/不OK或探索可依赖新打法新模式新产品(来自业务升级需求/旧渠道衰退)——要点：定义"跑通"=可复制可规模化(KOL投放：KOL分ABC类×素材文案ABCDE类→不同产品不同组合投放转化率和订单能稳定在数值范围)；一次投放成功1000单≠模型，只是单点动作
4. 长期系统工程：通过一系列工作让业务拥有某种能力/阶段性成果(中台/HR体系)——需6-12个月甚至2年蓝图，分阶段(中台666规划：6个月系统建设期六大模块+5-20种子用户跑通→6个月业务全面接入不重复造轮子→6个月标准化组件化)；没蓝图=跑腿打杂
- 前三类周期3-6个月(部分公司按季度)；第四类需看6-12个月+
**1.3 与协作部门对齐**
- 两类团队：业务团队(增长/服务/交付/生产供给，处于业务流程某环节) vs 职能支持团队(产研/HR/财务/法务，提供基础工具和效率系统)
- 业务团队对齐：先把指标按公式拆清(横向按用户分类加法/纵向按漏斗乘法：月活=新增活跃[新注册×激活率]+已有活跃[老用户×留存率])。两种协作：①跨职能作战单元对一个指标负责(运营+产品+研发；定义谁驱动谁支持，驱动者背核心指标，配合者共背但非第一指标——产品驱动激活率，运营第一指标是按版本按时提供物料，第二才共背激活率；Pinterest 按流量/转化/激活/留存/推荐各环节小团队) ②多团队各认领一部分数字(新增50万=运营渠道40万+BD 5万+产品自增长5万)。上下游：线索团队第一指标线索数量，第二与销售共背转化率，否则互相甩锅
- 职能团队对齐两原则：①短期与业务部门目标对齐(共背指标 或 我的工作是业务目标达成的前提) ②长期必须有独立规划反向驱动业务效率提升(调研同类系统→10个模块蓝图→与业务共识半年先做哪几个→形成产品自己的版本规划线)，否则呼之则来挥之则去一团混乱
### 2 目标拆解为靠谱行动计划
**2.1 常规逻辑三步**
- ①目标达成路径基本拆解——三步法：核心目标通过哪几件事/哪几个指标达成(进攻叠加：哪些数据要提升/降低/做出什么成果)→前提保障性条件(招多少人/研发保证哪几个版本上线/供给交付能力)→约束条件(钱/人/时间/工具系统资源限制，老板预期)。规划顺序：先看资源限制只能做几件事→让必备前提保障先按时发生(倒推时间)→再开展进攻
- ②对各分支战线设定预期，三种逻辑：a.多条战线赛马(不确定哪条能出，每条目标定高一点，谁先跑出30-50%就加投；渠道部门月1000万流量拆微信广告/KOL/SEM/信息流) b.每个环节恒定要求(对战场有清晰判断：总流量天花板2亿当下1亿、进店转化行业25%努力30%、成交8-10%、复购顶天30%，都达到目标即达成) c.关注先后顺序(前提保障先发生)
- ③结合约束调整规划，三个出口：a.用行业成熟工具/套路不造轮子(裂变/社群转化工具) b.找路径关键节点做减法，聚焦资源先解决最重要最高价值问题(操盘手课先验证目标用户愿不愿付费再做课) c.时间紧人有冗余→线性改多线并行。例增长负责人下半年3000万：5人→2人→先聚焦引流产品打开流量再做转化(或反过来)；人不变但9月要2000万→两条线两小分队同时推进+找外部可一带多的引流产品借鉴
**2.2 两种非常规问题**
- 模糊需定义的问题（老板抛现象：PR势能不高/社区氛围不好/团队士气/探索新方向）三步：
  1. 先把现象定义为待解决的具体问题，验证问题是否存在（口碑下滑→看满意度/NPS/推荐就业成功率→确实下滑→成因助教供应能力撑不住→问题定义为搭一套支撑更大吞吐量的助教业务模型；离职率6% vs 行业7%→不是问题用数据证明给老板）。最终落到：做新产品/开新渠道/验证新模式/巩固现有模型
  2. 只模糊不复杂→对外找可借鉴模型定行动计划（PR势能差→定义为老板担心对手融资威胁+PR驱动增长→在行约十几个PR专家各聊1小时→得到向投资人PR两种模型+PR驱动增长两种模型→给老板选项：投100-200万干2个月看成果）
  3. 既模糊又复杂→层层分解找破局点先行切入（创投媒体公司探索新业务：盘核心资源[企业家资源/行业影响力/活动社群能力]→产业链大机会[toB服务/职业教育政策/投融资服务/高端社群]→结合基因选职业教育+企业服务→目标用户需求[C轮前互联网创始人]→产品选项[数据SaaS/协同软件/高端咨询]→做法选项[自研/代卖/打包综合SaaS]→关键：无论卖什么toB都是卖解决方案需先诊断→破局点=培养一群牛逼的顾问式销售，有了什么都能干）
- 更高效路径=杠杆：先梳理一般达成路径→找一两件有杠杆效应的事显著加速(3渠道各200万→其中一个渠道倾注资源打透打爆做到400万)。三类常见杠杆：①拿下领域内最有影响力的头牌用户(美食社区电商月GMV100万目标：聊30多家零食品牌无人理→聚焦良品铺子2-3周全力服务人肉导流开店→搞定后中小品牌顺利入驻) ②先在细分渠道/领域成为头部(彭小六简书) ③先拥有稀缺资源/能力形成角色反转(供需动态平衡，找当下稀缺侧：喜马拉雅2015签阅文集团版权扩内容供给拉开差距；招聘网站每月BD一批前端简历，企业须注册上传职位才能看)；三类可叠加(拿下知名服装品牌+京东618细分品类头部+稀缺供给)；杠杆对执行力要求更高
**2.3 三类操盘手规划实例**
1. 增长类目标层层精细落地：电商类目半年月收入5-6万→100万+：锁定客单价，抓流量和转化率，按月定策略(11月打1-3个爆品月销30-60；12月爆款月销200，转化率锁1%，日订单1→28靠直通车/钻展加投；2-3月冲量转化率1.1→1.3→1.6靠清仓/团购活动，客单价降但算得平)。化妆品店年900万：按Q拆(Q1日销4600/UV1900找主推品打磨体验品引流+月度主题活动；Q2日销2万/UV5000找符合定位的爆品；Q3主推热卖特惠套装拉客单价；Q4爆款+活动+套装)。优秀规划三要素：明确的目标拆解逻辑+每个重要目标有明确抓手+表达对象清晰
2. 多战线方向性目标("一年内成为品类第一")：①先定义第一=课程体系最全/订单吞吐最大/口碑最好/行业权威背书 ②区分进攻叠加(订单/用户规模)与前提保障(其余三项)+约束(时间1年，资源可提) ③SMART化：学科地图下15门课/NPS≥60%/每月10万订单/5个头部KOL+5家公司背书 ④排先后：口碑和课程体系先发生(收入保障)，背书可靠后；订单=SKU×渠道×转化 ⑤找最优路径加杠杆：搞定明星用户/老师背书；先做一堂爆款课拥有头部效应；优先生产大家想要但稀缺的课程话题
3. 独立负责一条业务线自己定目标：先判断业务阶段(早期验证需求交付/有模型要标准化规模化/模型稳定加速增长)→四层问题：这事能做多大(全局方向：看出版行业存量/受众；看得到/喜马拉雅/知乎同板块数据；参照得到"垂类大咖一月3次上新"推演→月活50万)→怎么才能做这么大(找同类模型：持续免费IP话题上新/系列连载黏住/大量免费内容+分类索引消费路径→选后者)→真的能做到吗(验证：一条短视频生产10天供给可依赖？看过5条以上免费内容用户留存高20%→算账3000→3万条)→怎么做到(提免费内容供给效率+外部采购、用户引导按消费路径走+激励)。AB类操盘手先保证做好后两件，理解前两件逻辑
**3 进度管理两种**
- 瀑布流式：一环扣一环(需求分析→架构→文档→详细设计→代码→测试→上线)；要求提前把所有事的关系逻辑要点想清楚；风险预案只能A出问题用B，B不奏效无解；适合路径明确有经验的项目，强约束强考核强跟进
- 敏捷动态演化式(Scrum Sprint)：承认想不清楚先干；leader维护动态需求池(老板/自己/用户)→每周冲刺回顾更新需求池→每日站会同步；看板等工具；要求成员自主能动拥抱变化+leader能快速定义问题、快速反馈调整迭代；适合探索型项目

- 三节课酷产品(2016初)：先做业务逻辑假设(官方批量更新案例→定向邀请专业PM/运营解读形成讨论→卷入大咖和产品maker引发深度讨论带来关注)→三个关键排优先级(①围绕少量案例生成专业高质量讨论 最高→②引入大咖 次高→③案例批量更新 靠后)→聚焦关键①：初始内容填充+种子用户定向运营(引导/激励/互动/情感维系)；两个保障(内容生产互动工具、种子用户分层运营)→MVP：不开发工具，几十到一两百种子用户建邮件群组，每周更新7-10个案例，机制"发布自己观点后才能看别人的"，种子用户人肉维系→2个月跑通基础逻辑，小几百到一两千用户，势头好→被App Store封杀(威胁其地位)
- 探索=对项目最终长成什么样+怎么一步步长成有想象，据此规划行动路径，逐一解决障碍
- 完整商业故事三层：①商业价值构想(市场赛道/机会/商业模式/核心产品→能值多少钱) ②产品用户价值和业务逻辑构想(≈全局业务模型：用户价值/交付供给保障/模块关系) ③执行运作方式构想(≈局部业务模型：新渠道/新玩法/新转化产品/交付/供应链)。两个PH案例①②相同，差在③
- 探索项目成功至少=用户价值和业务逻辑稳定+局部业务模型成型
- 负责探索项目的前提：中大型公司要有公司战略和商业价值判断的全局认知(结构性机会判断会影响全公司模型，如2015 O2O all in)；必须有清晰的产品价值和业务逻辑假设；执行运作方式的构想要成熟能提出全面构想
- 全过程：从商业思考出发在三个层次提明确价值假设→沿假设快速行动→证实(放大价值完善模型)/证伪(回头重审假设)
### 1 基本工作逻辑四步
**1.1 形成业务模型层面的价值假设**
- 回到第三章模型分类框架找借鉴(增长获客：漏斗+话题内容/品牌PR/产品体验/社交关系链驱动+持续上新vs单品长周期；单体价值放大：生命周期典型路径/内容关系互动活动留存/分层/成长体系；交付保障：生产/交付/供给流通)
- 建议：对自己直接负责的模块，行业内常见相关模型要有清晰认知
- 案例知识付费平台(千聊/荔枝微课型，话题直播+系列课，平台抽成)：用户无留存无复购，靠一场场直播导流很累→复购属单体价值放大→借鉴：假设A 系列课后搭学习交流社区拉长留存周期再推荐其他课；假设B 系列课间建关联形成用户成长体系/学习路径(先A再B再C)推荐复购
- 形式："我有A问题，假设B模型/C模型能解决"，怎么形成B是下一步
**1.2 梳理所有价值假设点找权重更高的关键假设**
- 新业务链条两类问题：①价值会不会被用户认可(有没有复购动机、课程关联性是否存在) ②价值如何被创造(引导路径/机制/触达/激励/运营套路)
- 建议：优先解决用户会不会买/有没有动机用，再解决效率供给交付；供给交付中优先解决影响用户真实使用付费或交付基本前提的问题(滴滴拼车先控接单后等待时长，司机批量管理靠后)
- 案例操盘手课：面前N多问题(5000+单价/能否培养出操盘手/助教怎么找/内容谁讲/难点多/服务交付方式)→先解决价值认可：把自己当典型用户极致想象"做成什么样看到就想买"→结果价值(优秀学员认证推荐一线公司主管岗，接受推荐拿不到offer退50%；带真实业务问题学习每章作业围绕真实业务)+过程价值(按行业分小组研讨行业业务模型；助教须一线公司团队管理/重要项目负责人部分VP总监)→2019底活动现场300人+线上共四五百人公布内测4000元→15分钟120名额抢光=MVP验证价值认可无需怀疑→之后所有问题变成"怎么达到承诺"
- 价值如何创造：交付上"学习效果达成重于一切"→假设：解决底层三件事(商业思维/业务模型/复杂问题拆解)上层问题自然有解→业务模型梳理重于一切(梳理过程本身就在训练另外两个)→内测班聚焦一切资源验证用户能否理解习得业务模型(线上线下答疑/案例讲解)，其他(内容生产/教学服务/班主任配合冲突)先人工个性化解决，后期再规范化SOP→验证成功才放大公测正式班
- 总结：探索成功有N多要素当前都只是假设，找权重更高更基本的价值假设优先投资源
**1.3 按顺序验证直至证实/证伪：定量 vs 变量**
- 方法：有链条和模型→拉出关键影响要素→各要素中稳定找到定量(已验证/已被用户认可/当前已是yes)→确定变量且不能太多(太多注定失败)→反复测试；宏观层和微观业务流程层都适用
- 酷产品正例：商业价值构想=定量(国外跑通，除非想做10倍)；用户价值和业务逻辑=定量(已发生)；执行运作=变量→三个问题砍掉两个只留"定向邀请PM产生专业解读碰撞"→工具用邮件群组=定量、初始内容每周7-10案例=定量→变量只剩"怎么引导持续交流养成互动习惯"+"种子用户情感激励运营"
- 小H反例(知识付费平台用户运营)：原假设=用户分销把忠实用户发展为新渠道(只需验证有没有动机分销+有没有能力带订单，工具激励后想)→产品总监的测评社区针对同批用户→老板合并→妥协方案：忠实用户写作群每周每人写1篇课程测评发社区+附分销二维码传播分成→2个月群活跃但收入贡献<1%，100多篇内容优质少阅读传播低→关停→变量叠加(能否写出优质内容/有没有人看/看了能否转化/转化工具链路/社区流量怎么养)无定量→稀里糊涂失败，无法归因(人选不对？引导不到位？内容没分发？)，证实证伪都有价值，稀里糊涂失败毫无价值
- 铁律：N多变量叠加又无定量的探索项目注定失败；定量足够多足够稳定才有机会围绕少数变量完成验证
**1.4 增加资源投入放大模型**：闭环验证后投资源让交付过程和部门衔接标准化高效
### 2 三类常见探索型项目（编号：①商业价值构想 ②用户价值&业务逻辑 ③执行运作方式）
1. 从0起步做独立项目：先基于②产生用户价值假设→推演③形成工作计划→②③间反复验证校正→②稳定成定量→再基于②思考①。三节课2015-2017只想"线上课能否真实提升能力"，2017产品生产交付稳定后才想商业价值和模式。绝大多数创业公司和大厂独立新项目如此
2. 商业角度先发现结构性机会必须快速趟出通路：①=定量(哪个赛道存在结构性机会、能孕育多大公司、时间窗口多长)→基于①形成N多②③假想(窗口半年vs一年决定假想数量)→快速趟路多线并进找到一种可依赖打法→放大。360打百度(搜索格局老二必现拿10%+份额，窗口半年到一年，5条产品线同时跑)。亲历大厂A 2014群组社交APP(应对微信抢流量，投入不封顶)：一线视角=按社区规律慢养(建几百个主题群，最活跃是多肉群和成语接龙群→聚焦少量功能做扎实)；老板=要快要多，驱动探索直播/明星付费社区/KOL课程工具/财经付费专栏；一线不理解节奏混乱→数据滑落(一两千万用户后留存差)→失败。事后反思：这是结构性机会+明确时间窗口(2014一年，移动社交会出3-4款几千万上亿产品)，老板唯一命题=一年内找到一套打法成为某细分战场头部；老板在复用一个基本打法模型：绑定KOL/明星+快速投资源+抛话题→找到能规模化驱动增长的打法，在A/B/C哪个方向找不重要；按一线逻辑两年做出两三百万用户社区毫无意义。高层锁定结构性机会时，所有工作以它为定量展开，不纠结一线执行符不符合规律；半年多线快速出击拿结论，出来就放大，出不来就认了。腾讯微博两年、O2O大战同理
3. 基于现有业务体系解决一个问题(老板命题作文：供应链效率10倍/复购/获客成本降5倍)：①②中现有全局模型=定量，必须清晰理解，搞清我要解决链条哪段、哪些模块与我对接、input/output是什么→再形成③局部业务模型假设开启探索。文创电商案例：三条增长线(线下门店/淘宝+店铺CRM复购/其他线上渠道投放分销)→首购用户送权益导公众号内容留存→小程序二次转化；学员负责微信流量池系统化复购(与淘宝CRM完全不互通)→input=公众号稳定粉丝沉淀+小程序稳定首次转化，若不稳定要先往前解决；老板命题本身=定量(不用怀疑用户会不会复购，只需证实/证伪)→业务模型假设：用户成长体系 或 定期上新→关键要素(复购价值成立否/典型场景/动机/触达手段/运营工具)→先验证动机和价值：拉几百人用户群，结合热点基于文创IP上新品，用户下单预定够50个再生产→成立后再做触达机制工具场景；另一逻辑：把行业跑通的玩法(盲盒)当定量，产品适配性为变量直接套上跑
   - 产品经理做业务系统(CRM/效率系统)同理：先梳理全局业务逻辑在内部形成共识(三节课：内容素材→内容单元→课程类型→开班计划→可售卖课程→前端上线+营销玩法+用户权益→售卖→版本管理/分班/个性化内容→班级内容/学员工作/班级群；系统=内容管理/班期管理/营销管理/教学运营管理)→明确我的系统在哪个环节服务谁、input/output；不看全局直接做几版方案反复对不上效率极低
- 三类共用方法(模型假设→找权重最高假设→定量变量逐次验证)，但三层假设的关系不同
### 3 探索型项目三类典型障碍
1. 越往上靠近整体定位越开放变量越多(成型产品探索抖音新渠道=有定量 vs 独立探索一年营收5000万新产品=全是变量)→建议：先在稳定业务中做好局部探索或稳定验证小型产品用户价值，再参与更复杂综合项目；不具备能力可以认怂告诉老板不适合当前阶段的我
2. 完全没经验找不到模型指导(2015负责滴滴顺风车，行业无成熟参照)→先做业务逻辑基本假设(供需撮合匹配，服务+可能社交属性；需供给侧运营/交易撮合/司乘保障品控能力)→按第三章方法：检索相似行业(出行/电商平台/服务业)的相似模块(服务保障/交易撮合/供应链管理)→未解决问题(众包管理/线下社交关系缔结)再找同类问题解决方案(猪八戒威客供给端管理；线下交友活动关系缔结手段)。前提：对业务和用户深刻理解+熟知行业常见同类模型+善于快速学习
3. 项目复杂验证不扎实越做变量越多可依赖结论少稀里糊涂失败(学习社区：打标签→个性化推荐→持续学习养成习惯→留存→付费；第一环就撞上标签怎么打/内容稳定供给/内容组织/推了不爱看N多变量，四个人各管一线全不确定→无解)→两条：a.不要一开始多层假设嵌套，把要验证的变量限制在小范围(本质只验证"给用户针对性个性化内容用户会不会持续看"→人肉给100个用户推一批内容看会不会看，不看问原因；标签和内容组织是实现手段后置) b.长周期复杂项目每周每条线都要取得关键进展和结论，只允许最多1-2个问题周期长，其余支线不断赢得定量而非制造变量
- 提醒：80%+探索项目注定失败，但要明明白白地失败(基于明确逻辑假设知道哪想错了)；拥有某项关键破局能力(如文案销售转化超强)的人探索对应类型项目胜率高

## 第六章 团队管理
### 1 基本工作方法与逻辑
- 中层核心职责=对结果负责。高层定战略+业务模型 → 中层拿结果。管事线：定目标做规划 → 目标拆解到人（每人对什么负责背什么目标）→ 按阶段跟进（周/双周/月）→ 进展不如预期就调整：要么调事（方法逻辑）要么调人（人岗不匹配）→ 周期末（半年/Q）复盘 → 下一阶段
- 管人线：人才结构盘点（目标达成需要的核心能力素质，团队结构能否支撑）/ 各种谈话（绩效/发展/情绪/辞退）/ 团队凝聚力 / 重点员工辅导
- 管理观：对结果负责是根本；管好人是为了更好地对结果负责。氛围好但拿不到结果的团队毫无意义
- 案例小H（历史人文地理纪录片 APP 业务线，A轮160人，新项目3个月）：假想模型（大量纪录片+定期上新→留存活跃→付费→续费；获客靠自发分享/投放/自然回访）→ 目标 Q3 日活1万 → 公式 日活=新增用户×次留+当日新增 → 次留低是最大洼地 → 两条线（大量免费内容+稀缺内容引入：内容BD；内容消费路径：APP路径/小程序到APP路径/内容管理推荐上新：产品经理+内容运营）+新增强依赖投放 → **错误：1万指标只放自己身上，只给内容BD定了"每月8家PGC机构"，投放/内容运营/产品/小程序同学全无KPI，工作模式="这周帮我干三件事"** → Q3末日活2000 → 分析：投放用户太分散精细化跟不上留存低；看纪录片下载APP成本高小程序更优；高校大学生留存高于其他 → 调事：Q4 小程序为主载体、重点打高校、传统文化/社区话题 → 重梳模型（干掉渠道投放和自然用户；原有用户群+高校社团→小程序社区圈子话题运营→APP）→ 指标变小程序日活 → 分工：社区运营+产品经理共背次留；2个BD每月30个社团；活动策划每月几场活动每场多少新增；社群运营多少个群输送多少新增 → 目标没达成能分辨是BD不给力/社团导不上来/次留接不住
- 人的问题：团队转岗而来基础能力匮乏→员工辅导；方向调了三次动力缺乏→激励；老板传统媒体人不同频→定期汇报
- 回扣四特质：时间窗口有限，人撑不住目标就果断换人；基于假设不断调整模型；目标分解到每个人提清要求才可能拿到结果；管事管人都不可缺
### 2 八大管理工具（对应管理逻辑图各模块）
汇报框架 / 高效协作文档 / 目标管理+进度管理 / 复盘模板 / 人力结构盘点 / IDP / 1on1 / 团队发展与激励模型 / EDAC
**2.1 汇报框架（三类场景）**
- 规划型汇报 **5A**：Aspiration 愿景目标（占比短但要有）→ Assessment 全面评估（20%：背景/重点难点）→ Actions 举措建议（50%：每个问题障碍背后的思考）→ Action plan 实施计划（3-5个月怎么做）→ Advancement 推进保障（风险及防范/需要的前提保障）。例：老板我建议Q4集中探索小程序方向先拉高校用户，目标小程序日活3000；从市场/产品模式/参考借鉴评估；重点三点；第一个月BD 30家社团+线下活动看进展再规模化；需加两个高校BD、换产品经理
- 实施中进度汇报：背景（两个月前为解决X成立项目，简短）→ 执行情况（原计划 vs 现状）→ 评估（顺利则一切OK；有问题讲挑战和原因）→ 建议（不仅提问题还要回答问题）→ 需要的支持。例：高校BD 10个社团拉新1000月留存20%人力消耗大→这条路不太行→原因两点→建议换打法下月快速验证→需几点支持
- 问题解决型汇报：分析形势 → 界定问题（存不存在/真正影响因素）→ 原因分析 → 解决方案 → 判断与预期结果（多长时间/难度/什么条件下发生）
**2.2 目标管理+进度管理**
- 两种方式：①拆到人直接要结果（适合团队战斗力超强/目标清晰探索少/高度信赖/高层；高层长期冲一线=高层缺位）②既管结果也管过程（中层/战略级战线/需探索定义动态调整的项目）。AB类先学会管过程拿结果，再谈用人
- 周节奏进度管理：阶段性目标（Q内获客每天500-1000、付费转化5%→10%）→ leader 自己拆成每周计划（一线执行者不能让他们拆）→ 本周6件事（三套投放素材模板+5个投放计划上线下周看数据）→ 周一定计划 / 周三 review 进展不跑偏 / 周五 review 达成情况+讨论问题→调下周 → 下周一新计划。leader 主线=阶段目标/每阶段计划/达成情况/问题如何指导下阶段，不陷入具体执行问题，做支持者
- OKR 加餐（葛昊）：OKR 不是绩效考核工具而是人才观和管理理念，落实目标一致/信息透明/自由发声三要素；O=做什么 KR=怎么衡量；服务战略（3-5年愿景→1-3年战略→年度目标→1-3月阶段目标）；例产品部 O 提升首次用户体验 KR 找出并实施核心指标/首次登录三项实验符合预期>50%/发布两个迭代版本核心功能采用率+5%；运营 O 扩大新媒体内容影响力（而非粉丝数）KR 粉丝+2000/一篇10万+/200条销售线索；市场 O 确保线索和机会质量活性。注意：目标要有野心超出能力一点（不与工资挂钩）但上下级协调；O≤5 每O KR≤4 少写；KR 有截止日期可量化；60%自下而上（目标自上而下分解，KR 一线提）；达成共识非独裁（员工提意见双方一致才叫共识）。Uber 飞轮→拆O→KR跨部门→团队。打分满分1分0.6-0.7理想；过程比分数重要；全公司做；不与工资关联；听执行人意见。周期：Q前起草→中期review→结束总结打分公布新的。Google 绩效=自评（成就贡献影响力/好坏/责任）+同事评+经理据OKR和工作量定档→委员会分布（top5%杰出…需改进）。失败原因：管理层理解不到位靠HR推不动；缺信息系统支撑
**2.3 复盘模板（四步，一定基于目标）**
1 回顾目标（当初做什么事、目的、目标和里程碑）2 评估结果（哪些达成哪些未达成：超预期/达预期/不达预期/不可评估）3 分析原因（分主观客观；**成功多看客观（运气/红利），失败多看主观**）4 总结规律+下步行动（沉淀经验规律；行动分 继续保持/停止做/新开始做）。例产品团队OKR复盘：O1 100% O2/O3 70% O4 40%→有效：复盘反馈机制、中台化思考进步；需改进：与研发和业务协作差、推进无节奏感→Q3重点+两件新事+协同方案
**2.4 人力结构盘点 + IDP**
- 人力盘点场景：中层承担有挑战的任务、团队十几人以上→评估结构能否支撑一年内目标。工具=绩效×潜力九宫格（S/A1/A2/B1/B2/B3/C/D），B 为合格，S 高潜；S+A 占比至少约30%才积极；多在 B/C/D 目标难实现。得出最缺哪类人（高潜有成长空间 vs 一堆没潜力出不来业绩）→指导人员工作重点。可求 HR 支持
- IDP 个人发展规划（王刚）：结合岗位需要+个人意向，管理者与员工沟通达成共识的系统性提升计划；典型场景年度/季度总结。四模块：①工作回顾与评价（具体指标事实；含组织贡献如带新人/面试/团建/分享；上级写满意否、原因、哪些指标未达、哪里可更好）②个人优势与成长机会点（用"机会点"不用"缺点"，动态具体：如"了解客户需求方面可做更多"优于"沟通技巧不足"；用 STAR 提问核实；抓关键不求多；对应岗位胜任力模型）③职业兴趣探索（1-3年短期、3-5年长期，>5年不纳入；维度岗位/职级/薪资/地点/行业，引导排序）④下一步培养计划（有时间有产出可考核；共性需求集中培训）。流程：员工先填→上级补充评价→1小时深度一对一→书面记录→至少每季度回顾。注意：有仪式感（打印纸本、无人打扰会议室、整天只做这件事）；少说多听多问以启发为主（做蜡烛点燃自主进步动力）
**2.6 1on1 沟通**
- 场景：目标传达/过程管理/结果反馈/绩效沟通/情绪管理/离职留任/任务复盘
- 三长两短反馈法：先说三个做得好的（有事实数据：独当一面负责服务号/22篇推文转化率+2%/内容质量提升阅读分享率涨/主动复盘/拓展边界做增长活动新增8000粉）→再说两个可提升的（内容相比行业优势水准还不够；偏执行，Q1 要加强全局规划不要等我提需求）→补充点评。上对下、下对上都适用，有理有据引导到积极氛围
- PLAN 模式（王刚）：管理者发言≤30%员工≥70%；30分钟左右最长1小时（重要且打开了就聊透）。P Purpose 开场说清目的和时长+破冰（"你来两个月了今天花20分钟聊聊状况"/年终"一小时：你先介绍业绩→我点评评估→一起讨论发展计划"；关心病假家事、递水零食）；L Listen 先让员工说，开放式问题（"你给自己打几分""先回顾一下这一年"），不先抛观点否则抵触；A Ask&Answer 多提问不否定（想转岗→问为什么；状态不好→关心具体什么事；要升职加薪→问为什么现在/动机/长短期期望），了解够了再针对性反馈（好的肯定、不足批评+改进计划；当场解决不了记本子上给回复时间点）；N Next step 有结论，员工写沟通纪要邮件发管理者，含员工改进计划+管理者提供的支持（双方承诺），后续在此基础上续发。氛围：谈心不是审问，复述再提问，90度侧坐/边走边聊，先心情后事情
**2.7 团队发展与激励模型（四阶段）**
| 阶段 | 成员状态 | leader 重点 |
| 建立期 | 彼此陌生、未来模糊、不安不信任 | 面对面会议定义目标/团队架构/协作方式/每人角色/工作方式/决策程序（什么要请示什么可自决，授权讲清）；**就职演说**（先花两周接触上级/重要下属/兄弟部门/关键客户再讲；三部分：个人职场生活经历建立信任+管理风格[最希望的工作方式/最欣赏的品质/不能容忍的底线把丑话说前面]+工作方向[与前任异同]；定了规矩要执行，触犯底线要杀鸡儆猴，别一上来三把火） |
| 磨合期 | 困难冲突大量出现、个人喜好前置、信任未建立 | 身先士卒搞定下属搞不定的事（K12校长案例：每天200个电话先做销售冠军，帮资深销售拿大单，才获信任）；大量1on1了解顾虑；重新审视目标和角色分工微调；及时介入调节冲突甚至创造环境公开冲突（会议末留十几分钟畅所欲言）；每人承担一部分公共项目（对接财务/学习协调者/行业动态/轮流组织团建）制造链接 |
| 成型期 | 有合作规则/工具流程制度，关注目标而非关系，有归属感接受角色 | 提升信任三件事：集体记忆（誓师大会、集体反省集体解决问题）、体验高峰（制造惊喜时刻不平铺直叙）、里程碑事件（整数关口用户破10万销售破100万及时传递；Uber "N的N次方"；杭州最高旋转餐厅庆祝破纪录） |
| 表现期 | 目标被实现、里程碑刷新、士气高、不惧冲突互相指着鼻子要支持 | 保持高绩效：退居二线支持自我领导；晋升优秀员工送出去；吸引新成员并授权老员工带新人建梯队；引入更高挑战避免自大 |
每阶段建立在前一阶段上；遇到新挑战新任务阶段会重新开始
**2.8 EDAC 培训辅导技术（宝洁管培生起源）**
- E Explain：讲清是什么/为什么（对公司和个人的意义、重要性）/怎么做（拆解步骤、流程、关注重点、给框架模板）；必要时让员工复述确认理解。反面："周五前帮我把宣传稿写好"信息不足
- D Demo：完整标准可复制的流程示范（看我做一遍 / 看同事成功案例完整复盘文档）；以新人视角不省略；也是管理者保持与一线接触的机会
- A Apply：给子任务真刀真枪试；观察+事后反馈（好的/可提升/下一步改进；让员工先自评再点评）；忌控制欲太强（偏离就打断→记录事后反馈，可承受范围内让他狠狠失败一次）和心太软（跳步结果没出事就放过→必须指出重走四步；任正非"先僵化后优化再固化"）
- C Consolidation：实战演练持续布置类似任务关注熟练度；或高压模拟任务（扮演谈判对象制造麻烦打断呵斥；每周一篇宣传稿集中训练；姚明体力耗尽时练罚球）；员工压力大时不宜
- 宝洁管培生8周：四模块（管流程/管客户/管生意/管团队）各有课程→内部成功案例库→尝试任务（独立完成一次客户拜访并填日志/独立卖进3个新品分销上架/完成一次促销结果分析并与客户回顾/召集一次销售代表会议辅导业绩）→考试（角色扮演促销宣讲/专题汇报如何提升新品卖进率/品类知识陈列标准笔试）
**2.9 小结**：管事为主，先看当前主要问题是事没管好（目标进度？协作？）还是人没管好（凝聚力士气？），再定向选工具
