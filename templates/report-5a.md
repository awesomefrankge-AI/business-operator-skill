# 向上汇报模板（三类场景）

## A. 规划型汇报 · 5A
1. **Aspiration 愿景目标**（短）：解决什么问题、目标数字、达成后意味着什么
2. **Assessment 全面评估**（~20%）：背景、市场 / 产品模式 / 参考借鉴、重点难点 → 结论目标可否达成
3. **Actions 举措建议**（~50%）：重点 1/2/3，每点背后的思考
4. **Action plan 实施计划**：第 1 个月 / 第 2-3 个月 … 看到什么再决定是否规模化
5. **Advancement 推进保障**：需要的人 / 资源 / 前提；风险及防范

## B. 实施中进度汇报
1. 背景（一两句：X 个月前为解决 Y 启动 Z）
2. 执行情况（原计划 vs 现状，数字）
3. 评估（顺利 → 一切 OK；有问题 → 挑战 + 原因）
4. 建议（不只提问题，给答案）
5. 需要的支持

## C. 问题解决型汇报
1. 分析形势
2. 界定问题（存不存在？真正影响因素？数据）
3. 原因分析
4. 解决方案（可选项 + 推荐）
5. 判断与预期（多长时间 / 难度 / 什么条件下发生）
