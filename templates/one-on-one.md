# 1on1 沟通模板

## 三长两短反馈法
- 三长（做得好，有事实数据）：1. 2. 3.
- 两短（可提升，指向下阶段期待）：1. 2.
- 补充点评：

## PLAN 模式（管理者说 ≤30%，30-60 分钟）
- **P Purpose**：本次目的 / 时长 / 议程；破冰（关心近况）
- **L Listen**：开放式问题先让对方说（"你给自己打几分""先回顾一下"）
- **A Ask & Answer**：追问（为什么 / 具体什么事 / 动机 / 长短期期望）→ 再反馈（肯定 / 批评 + 改进计划；当场解决不了的记录并给回复时间）
- **N Next step**：员工写纪要发我，含员工改进计划 + 我提供的支持

场景：☐ 目标传达 ☐ 过程管理 ☐ 结果反馈 ☐ 绩效 ☐ 情绪 ☐ 离职留任 ☐ 复盘
氛围：谈心非审问；复述再提问；侧坐 / 边走边聊；先心情后事情
