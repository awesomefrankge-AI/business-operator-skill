# 老板抛问题：五层响应表

> 用法：老板抛一个想法 / 问题，先判断他在哪一层，再按该层给答案。同一问题在不同日子可能换层。

- 老板原话：
- 当前公司阶段 / 老板此阶段最关心：
- 判断层次：☐ 1 验证战略方向假设 ☐ 2 评估商业模式 / 成本模型 ☐ 3 业务模型分支模块怎么搭 ☐ 4 执行落地路径 ☐ 5 某件事怎么执行更好
- 判断依据：

| 层 | 老板内心的问题 | 应给的答案 |
|---|---|---|
| 1 | 在什么市场做什么产品更靠谱 | 需求成立否 / 可行性 / 供需两端调研 / 往哪个方向 |
| 2 | 供给交付营销要不要升级、靠谱程度 | 基于假设的财务成本估算 + 对现有业务模型的影响 |
| 3 | 新模块分哪些部分 | 模块整体模型 + 重点难点 |
| 4 | 怎么干成 | 计划 / 里程碑 / 时间 / 需要的资源 / 承诺结果 |
| 5 | 某难点怎么弄 | 3 种思路，我推荐哪个，请确认 |

- 若是模糊现象（"势能不够""氛围不好"）：先把现象定义为具体问题并验证是否存在（拿数据）→ 只模糊不复杂：找外部模型给选项 → 既模糊又复杂：层层分解找破局点
