> 用法：局部 = 全局链条的某一环。先定 input/output，再判断靠流程还是靠分工，再补约束机制。简单业务流程画出来就七八成；复杂业务（角色多 / 用户类型多）先列角色再串流程。

- 在全局链条中的位置 / 上游给我什么 / 我给下游什么：
- 对接的业务方：

| 项 | 内容 |
|---|---|
| input（资源 / 人 / 钱 / 初始状态用户） | |
| output（稳定标准的业务价值：转化率 / 满意度 / 人效 / 收入 / 成品） | |
| output 主要靠 ☐ 流程保障 ☐ 分工协作机制保障 | |
| 角色分工（每个角色做什么、关系） | |
| 业务流程（步骤 → 步骤） | |
